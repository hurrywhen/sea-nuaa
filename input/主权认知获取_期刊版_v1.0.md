# 1. 引言

信息富足会造成注意力匮乏 [1]。这一约束是定量的，而非修辞性的。若某智能体每日拥有 \(T=45\) 分钟，每条实质性条目至少需要 \(\underline\tau\approx4\) 分钟，而订阅、通知、搜索结果和社交流合计提供 \(N\sim10^4\) 个候选，则只能消费约十条。因此，被丢弃的比例必须约为 99.8–99.9%。工作记忆与上下文窗口的限制使人类与人工智能体面临同样的结论 [2]。过滤不可避免；科学问题在于：由谁控制过滤、过滤应获取什么，以及激进选择何时仍然安全。

本文讨论现有处理中彼此脱节的三处。第一，推荐或交付系统可能优化某个可观测代理指标，却未能优化智能体经反思后认可的目标。我们区分第一序冲动 \(g^{(1)}\) 与第二序目标 \(g^{(2)}\)，这一区分遵循分层能动性观 [3]。数字消费所显示的偏好与福利之间的背离为这一区分提供了经验动机 [4,5]，但其在本研究中的作用是规范性的：获取目标的写入权属于智能体的反思层，而不属于平台或内容流。第二，推送与拉取常被分开处理。过滤对到达内容进行排序，而检索、信源探索与监测会重塑可能到达的内容。两者消耗同样的时间，也都会改变后续决策；彼此分离的目标使其边际价值无法相互定价。第三，高召回往往仅通过改进评分来追求。然而，在极端准入率下，分离度与容量会施加任何排序承诺都无法消除的限制。

我们将由此形成的表述称为**主权认知获取（SEA）**，并将其优化核心称为**主权获取问题（SAP）**。SAP 将监测、主动获取、推送选择、交付与反思视为一个受约束的随机控制问题。主权不是另一个可以拿来交换的奖励项。它通过四项条件限制可行策略空间：**S1 可检查性**、**S2 经授权的写入**、**S3 不受第三方目标俘获**与 **S4 可审计性**。这些条件与推荐系统价值观研究以及从参与度推断一致用户目标之困难的研究形成互补 [6,7]，但它们改变的是控制权的归属，而非仅仅提出一个更好的平台侧目标。

本文作出五项理论主导的贡献。

1. **统一问题与条件性价值分解。** SAP 在 S1–S4 下将推送、拉取与反思分配到共同预算。期望实现决策价值按数据生成的真/假分支分解，使通常的 Blackwell 信息价值与误设更新下的负价值能够无矛盾地共存。只有在决策同质性与特征充分性假设共同满足时，常见的五特征评分才被证明是精确摘要。
2. **过滤瓶颈与架构应对。** 预算–分离度–召回恒等式同时给出分布无关的容量上限与高斯分离度要求。在一个代表性的命题级运行点上，95% 召回要求 \(d'\geq4.39\)，AUC 约为 \(0.999\)。因此，命题坍缩与双通道设计以结构方式承载召回，而不要求评分器近乎全知。
3. **条件性冗余覆盖保证。** 独立信源类给出 \(P(\mathrm{miss})\leq(1-p_{\min})^k\)。独立子集构造在任意依赖下将 \(k\) 替换为 \(k_{\mathrm{eff}}\)，且在没有进一步假设时是紧的。观察清单直通、监测分配与双通道总召回界补全了这一架构。每项数值保证仍始终以 \(p_{\min}\) 的来源与标定为条件。
4. **主动与被动获取的共同价格。** 注意力无套利结果被明确表述为一个**统一定理**，而非对新的 KKT 数学的主张。它围绕同一影子价格组织 Pandora 探索、边际价值停留、推送阈值、查询批次与反思。期望信息增益提供了单调的查询目标，并在条件独立下提供次模查询目标。
5. **明确边界与限定范围的验证。** 精选的目标俘获扩展通过检测召回、暴露上限与单条目影响有界来约束有效评分漂移。随后，已完成的学术域与金融域试点以及四家族判断层重放检验机制并映射失败。它们既不确立人类效能，也不完成完整 P1–P12 计划，更不为耦合 SAP 提供全局近似比。

本文的侧重点有意区别于一篇配套的六页实证会议论文及完整专著 [55]：本文围绕假设、定理链、证明与适用域边界组织。实证比较被压缩到第 10 节，用作验证与证伪映射，而非主要贡献。

# 2. 相关工作与定位

## 2.1 动态获取与注意力分配

拉取侧借鉴了若干成熟传统。搜索经济学将额外检查的成本与其预期收益相权衡 [9]；Pandora 规则为独立备选方案在检查有成本时给出指数策略 [10]；最优觅食与信息觅食将补丁离开与边际摄入率联系起来 [11,12]。理性疏忽则对信息处理收费，并产生内生随机选择 [13–15]。序贯实验设计与主动学习根据预期决策增益或信息增益选择观测 [16–20]，而 Gittins 与不安定 bandit 表述处理在演化信源之间的持续分配 [21,22]。一般不安定问题在计算上很困难 [23]。

Zhong 的最优动态信息获取是拉取侧最接近的形式理论前驱 [8]。二者关系可以精确说明。将 SAP 限制为：(i) 仅含拉取，推送与反思预算为零；(ii) 无对抗分支，因而实现价值退化为非负 VOI；(iii) 主权限制不激活；(iv) 固定 \(g^{(2)}\)。所得问题就是在获取预算下对信息结构进行序贯选择。SEA 的独特内容位于其补集：逐期推送选择、结构性召回、误设更新下的负实现价值，以及对目标本身的授权控制。我们不主张反向归约，也不主张在动态获取指数化方面的优先权。

我们的无套利结果同样没有发现边际均等化。其贡献在于表明，探索准入、补丁离开、推送消费、查询投入、监测轮换与反思都可以依据同一预算影子价格接受审计。这种统一具有操作意义：当搜索与信息流消费的边际价值可以比较时，额外的十分钟就不必凭习惯分配给其中任何一方。

## 2.2 价值、过滤与覆盖

Blackwell 的实验排序与信息价值理论提供了非负信息价值基线 [24,25]。信号检测论提供分离度度量 \(d'\)，用于为不完美关键性评分定价 [26]。次模福利与覆盖结果提供经典贪心保证 [27–30]，重尾价值模型则促使我们给出显式失真界 [31]。这些都是标准工具。本文的综合在于：将分离度结果用作纯评分的不可能性边界，并将覆盖结果用作条件性架构保证，而不是把评分质量与信源结构视为可以互换。

这一区分也使 SEA 不同于仅报告排序质量的检索评估。排序器可以不断改进，却在固定且极小的准入率下仍无法达到召回目标。反过来，一个信源组合可以拥有大量冗余覆盖，而其条目仍然排序不佳。这两个量必须分别测量。

## 2.3 错误信息、推荐与溯源

事后纠正有用但并不完全 [40,41]，因此，事前暴露控制是纠正的合理补充，而非替代。若不顾容差与信任而强加对立观点，接触这些观点可能产生反噬 [42]；认知气泡也不等同于回音室 [43]。因此，本框架既不把主权等同于最大化个性化，也不把它等同于随机“打破气泡”。暴露多样性与信息流治理文献提供了面向公共层面的替代方案和补充 [44–47]，但本文有意不纳入公共层扩展。

最后，信念形成无法消除证词；只能选择并审计其溯源 [48,49]。因此，信源身份、所有权、转述链以及可获得时的内容凭证 [50] 都进入形式模型。它们并非装饰性元数据：覆盖独立性与观察清单保证都依赖于这些信息。

# 3. 前提与主权约束

## 3.1 前提的地位

SEA 将经验假设、规范承诺与设计立场区分开来。这种区分防止某种价值立场悄然进入概率界。

| 前提 | 地位与操作内容 |
|:---|:---|
| 有界性 | 经验假设：时间、工作记忆、上下文或推理预算有限。 |
| 供给过剩 | 经验假设：候选到达成本远超可用注意力。 |
| 目标分层 | 规范承诺：经反思认可的 \(g^{(2)}\) 对 \(g^{(1)}\) 具有权威。 |
| 证词依赖 | 经验假设：重要信念依赖中介化信源。 |
| 对抗性 | 设计立场：内容可能试图未经授权地写入信念或目标。 |
| 可纠正性 | 设计立场：性能可测量，且始终可以回滚。 |

: 表 1. 前提状态：经验假设、规范承诺与设计立场。

这些前提蕴含设计要求，而非无条件经验事实。特别是，程序性认可并不能证明 \(g^{(2)}\) 是真实的，也不能证明其不受适应性偏好形成的影响 [51]。可辩护的要求更为有限：目标形成与参数更改应当可检查、有日志、可逆，并向非退化的信息输入开放。

## 3.2 作为可行策略限制的 S1–S4

令 \(R\) 表示反思层：对于人类智能体，它是本人；对于 AI 智能体，它是委托人的合法授权配置。系统 \((\pi,U)\) 在满足以下条件时具有主权性。

| 条件 | 形式与操作要求 |
|:---|:---|
| S1 可检查性 | \(U\)、\(g^{(2)}\) 与权重可读取；所声明的评分表示含有数量有界的可解释项。 |
| S2 写入权 | 对目标、权重、阈值或监测清单的更改需要显式授权 \(\sigma_R\)；行为可用于测量，但不得悄然写入。 |
| S3 不受俘获 | 任何第三方收入项均不得进入 \(U\)；反事实排序探针检验对平台侧变量的不变性。 |
| S4 可审计性 | 准入、排序、参数写入与交付均留下解释以及仅追加、可发现篡改的记录。 |

: 表 2. 作为可行获取策略限制的主权条件。

S1 并不主张简短表示始终是充分统计量；第 5 节证明，在决策同质性之外情况并非如此。S2 是内容通道与参数通道之间的关键隔离。内容可以更新知识 \(K\)，但不能直接修改目标。S3 是所有权条件，并不主张平台从不产生有用信息。S4 提供质疑或回滚某项决定所需的证据。

形式上，S1–S4 定义了受限策略类 \(\Pi_S\subseteq\Pi\)。它们并不向效用添加“主权奖励”。这可以防止优化器通过交出控制权来换取参与度或短期 VOI。每次参数修改还必须具有历史可追溯性与可逆性；即使书面目标看似无害，由迁移壁垒或默认惯性造成的切换成本也违反这一设计。

# 4. 信息环境与主权获取问题

## 4.1 信息条目、命题与智能体

一个信息条目为
\[
x_i=(\mathrm{content}_i,\mathrm{prov}_i,\tau_i),
\]
其中，\(\mathrm{prov}_i\) 记录信源与传递溯源，\(\tau_i>0\) 为消费时间。潜在属性包括期望实现决策价值 \(v_i^*\in\mathbb R\)、操纵强度 \(m_i\in[0,1]\) 与立场 \(s_i\)。后文覆盖与失真效用中使用的、仅计收益的价值 \(v_e\) 为非负；而在误设更新下，实现价值可以为负。可观测特征依赖于状态：
\[
\phi(x_i;K,D)=(\mathrm{relevance},\mathrm{novelty},\mathrm{durability},
\mathrm{actionability},\mathrm{credibility})_i\in[0,1]^5.
\]
新颖度取决于当前知识 \(K\)，相关度与行动性取决于声明的决策集 \(D\)；因此，\(\phi\) 不是仅由条目决定的函数。

文档通过 \(\kappa:X\to E\) 坍缩为底层命题。每个命题 \(e\) 具有文档集 \(D_e\) 与一棵溯源树，其根节点是一手信源，分支包含转述与评论。坍缩比为 \(\rho_c=|X|/|E|\)。信源依据所有权、地域、类型及上游通讯社依赖被划分为 \(\mathcal C_1,\ldots,\mathcal C_K\)。对于类别 \(i\)，覆盖事件为
\[
Z_i(e)=\mathbf 1\{\exists x\in D_e:\mathrm{source}(x)\in\mathcal C_i\}.
\]
这一构造旨在减少跨类依赖，而不是假设其不存在。

智能体为 \(\mathcal A=(C,G,K,\theta,R)\)，其中，\(C=(T,W)\) 表示容量，\(G=(g^{(1)},g^{(2)})\) 表示目标，\(K\) 表示信念与已消费命题记忆，\(\theta\) 是慢变认知状态投影，\(R\) 是反思层。每个决策 \(d\in D\) 具有效用 \(u_d(a,\omega)\) 与截止期 \(h_d\)。若关于某命题的信息以非零概率使某项活跃决策发生超过声明幅度的改变，则该命题是**关键的**。因此，关键性相对于主体而言，而非普遍的新闻价值标签。

策略为 \(\pi=(\pi_{\mathrm{mon}},\pi_{\mathrm{pull}},\pi_{\mathrm{push}},\pi_{\mathrm{del}},\pi_{\mathrm{esc}})\)，分别对应监测、主动获取、推送选择、交付与预先授权的紧急处置。其预算恒等式为
\[
T=T_{\mathrm{pull}}+T_{\mathrm{push}}+T_{\mathrm{ref}}.
\]
反思不是免费的剩余时间；它是一种具有自身边际价值的竞争性用途。

## 4.2 SAP 与优化范围

对于视界 \(H\) 与折扣 \(\beta\in(0,1]\)，SAP 为
\[
\max_{\pi\in\Pi_S}\ \mathbb E_\pi\!\left[\sum_{t=1}^{H}\beta^t
\big(\mathrm{VOI}_t(A_t)+\zeta\Delta\theta_t-\mathrm{Harm}_t(A_t)\big)\right]
\tag{1}
\]
并在每一期满足
\[
\sum_{i\in A_t}\tau_i+c(\pi_{\mathrm{pull},t})+c_{\mathrm{ref}}\leq T,
\tag{2}
\]
以及声明的操纵暴露、容差带、主权与紧急结构约束。VOI 与伤害使用相同的决策效用单位。兑换率 \(\zeta\) 是声明的慢时间尺度权重，而非估计得到的普适常数。本文分析获取与过滤核心；不主张人类德性动力学的收敛性。

**命题 4.1（有限期存在性）。** *假设 \(H\) 有限、每期收益有界、每期候选池有限且拉取算子组合有限、约束封闭，并且空行动存在且可行。则存在最优确定性马尔可夫策略。*

**证明。** 令 \(s_t\) 包含 \(K_t,\theta_t\)、剩余预算与监测状态。设 \(V_{H+1}=0\)，并递归定义
\[
V_t(s_t)=\max_{a_t\in\mathcal A_t(s_t)}
\{r_t(s_t,a_t)+\beta\mathbb E[V_{t+1}(s_{t+1})\mid s_t,a_t]\}.
\]
每个行动集均为有限集，因此每个最大值都能达到。反向归纳由此在每个状态与时期给出最优行动规则；将这些规则拼接即得最优策略。S1–S4 只是从有限可行集中移除行动，并不改变这一论证。\(\square\)

存在性不等于计算上的可处理性。SAP 包含不安定 bandit 特例，本文不主张一般的全局高效解法。后续各节推导逐层刻画与保证。这些近似比与误差界通过共享预算和知识状态**不会自动组合**。特别是，本文不对分层 SAP 提出全局近似比主张；强耦合情形下的组合仍是开放问题。

# 5. 期望实现价值与特征评分的局限

## 5.1 正确更新与误设更新

对于正确设定的实验 \(\sigma\)，定义
\[
\mathrm{VOI}(\sigma)=\mathbb E_y\!\left[\max_a\mathbb E[u(a,\omega)\mid y]\right]
-\max_a\mathbb E[u(a,\omega)].
\]

**引理 5.1（Blackwell 价值非负）。** *在正确似然下，\(\mathrm{VOI}(\sigma)\geq0\)。*

**证明。** 先验最优行动 \(a_0\) 在每次观测后仍然可选。因此，对于每个 \(y\)，
\[
\max_a\mathbb E[u(a,\omega)\mid y]\geq \mathbb E[u(a_0,\omega)\mid y].
\]
对 \(y\) 取期望并使用全期望公式，即得 \(\mathrm{VOI}(\sigma)\geq0\)。等价地，最大值关于后验是凸的，因而可应用 Jensen 不等式。\(\square\)

当对抗内容导致按错误似然更新时，它并不与该引理矛盾。令 \(z\) 的真实分布为 \(Q_z\)，智能体使用似然 \(\ell\)，形成后验 \(\mu_K^\ell(\cdot\mid z)\)，并选择 \(\hat a(z)\in\arg\max_a\mathbb E_{\mu_K^\ell}[u_d(a,\omega)]\)。期望实现价值为
\[
W_d(z;\ell)=\mathbb E_{z\sim Q_z}\mathbb E_{\omega\sim P(\cdot\mid z)}
[u_d(\hat a(z),\omega)]-\max_a\mathbb E_{\mu_K}[u_d(a,\omega)].
\tag{3}
\]
正确更新给出 \(W_d=\mathrm{VOI}_d\geq0\)；误设更新可以给出 \(W_d<0\)。(3) 中的期望按真实联合分布取值，而非按智能体可能错误的预测分布取值。

## 5.2 分解假设

该分解使用六项显式条件。

- **V1 决策相关性。** 条目价值通过 \(D\) 中的活跃决策进入，相关度—活跃度权重为 \(\pi_d(i)\)。
- **V2 双分支有界伤害。** 以概率 \(c_i\)，真实信号得到正确更新；以概率 \(1-c_i\)，对抗信号被当作真实信号，产生位于 \([0,\mathrm{Harm}_{\max}]\) 内的实现伤害。
- **V3 时效性。** 决策 \(d\) 的真分支价值按 \(e^{-h_i/\lambda_d}\) 折扣。
- **V4 决策同质性。** 各决策共享 \(\lambda_d=\lambda\)，其价值与伤害剖面仅相差与条目无关的权重 \(a_d\)：\(\mathrm{VOI}_i^{(d)}=a_dV_i\)，\(\mathrm{Harm}_i^{(d)}=a_dH_i\)。
- **V5 分支—更新一致性。** 数据生成的分支指标与 V2 中的更新规则相对应。
- **V6 特征充分性与伤害标定。** 特征映射确定 \(A_i,V_i,h_i,c_i\)，且 \(H_i\) 要么是经标定、与条目无关的常数 \(H\)，要么是增广特征映射 \(\tilde\phi\) 的一个附加坐标。五个基础特征的精确性要求共同 \(H\) 的情形；若伤害随条目变化，则必须使用增广映射。

V5 是一项实质性条件。以下分解是对分支取全期望，而非 VOI 对后验混合的线性化。

**定理 5.1（期望实现价值分解与条件性精确摘要）。** *在 V1–V3 与 V5 下，*
\[
v_i^*=\sum_{d\in D}\pi_d(i)\left[
 c_i\mathrm{VOI}_i^{(d)}(y_i)e^{-h_i/\lambda_d}
 -(1-c_i)\mathrm{Harm}_i^{(d)}\right].
\tag{4}
\]
*若 V4 也成立，且 \(A_i=\sum_d\pi_d(i)a_d\)，则聚合因子分解为*
\[
v_i^*=A_i\left[c_iV_ie^{-h_i/\lambda}-(1-c_i)H_i\right].
\tag{5}
\]
*若 V6 也成立，则存在与条目无关的 \(F\)，使得 \(v_i^*=F(\tilde\phi(x_i;K,D))\)。在共同伤害情形下 \(\tilde\phi=\phi\)；否则 \(\tilde\phi\) 包含 \(H_i\) 作为一个坐标。因此，V4 给出聚合因子分解，而精确特征摘要要求 V4 与 V6 同时成立。*

**证明。** 由 V1 得 \(v_i^*=\sum_d\pi_d(i)W_i^{(d)}\)。对数据生成分支取条件。由 V2 与 V5，真分支贡献 \(\mathrm{VOI}_i^{(d)}\)，其概率为 \(c_i\)；假分支贡献 \(-\mathrm{Harm}_i^{(d)}\)，其概率为 \(1-c_i\)。全期望公式给出
\[
W_i^{(d)}=c_i\mathrm{VOI}_i^{(d)}-(1-c_i)\mathrm{Harm}_i^{(d)}.
\]
V3 仅将真分支价值乘以 \(e^{-h_i/\lambda_d}\)；代入即证明 (4)。在 V4 下，代入 \(a_dV_i\)、\(a_dH_i\) 与 \(\lambda\)，再从求和项中提出 \(a_d\)：
\[
\sum_d\pi_d(i)a_d[c_iV_ie^{-h_i/\lambda}-(1-c_i)H_i]
=A_i[c_iV_ie^{-h_i/\lambda}-(1-c_i)H_i].
\]
这证明了 (5)。在 V6 下，所有其余依赖于条目的参数均由声明的特征映射确定。在共同 \(H\) 的情形下，基础映射足够；否则增广映射包含 \(H_i\)。固定参数 \(\lambda,\{a_d\}\) 与经标定的伤害规格随即定义了与条目无关的 \(F\)。\(\square\)

两项限定可避免过度解读。第一，(4) 不是某个混合实验的 Blackwell VOI：不同分支使用正确与错误的似然，因此实现价值可以为负。第二，聚合因子分解 (5) 不能去掉 V4，精确特征摘要的解读也不能去掉 V6。若条目 \(i\) 仅影响一个 \(\lambda_1\) 较小的紧急决策，条目 \(j\) 仅影响一个 \(\lambda_2\) 较大的持久决策，且二者的聚合五维特征相同，则其价值分别正比于 \(e^{-h/\lambda_1}\) 与 \(e^{-h/\lambda_2}\)。相同特征不必意味着相同价值。即使在 V4 下，若不对伤害进行标定或将其纳入特征映射，相同的基础特征仍可对应不同的 \(H_i\)。

当 V6 成立时，精确的 \(F\) 是乘性的，通常并非线性评分 \(\langle w,\phi\rangle\)。对数收益特征可以使正项可加，但伤害项不处于同一对数空间。因此，SEA 主要通过硬暴露约束与防火墙处理伤害。在 V4 与 V6 之外，本文不主张精确特征摘要，也不主张线性评分与 \(F\) 之间存在近似界；实测分离度用于为由此产生的排序误差定价。

## 5.3 一个闭式锚点

**推论 5.1（高斯—二次 VOI）。** *令 \(\omega_d\sim\mathcal N(\hat\omega,\sigma_0^2)\)，\(y_i=\omega_d+\epsilon\)，\(\epsilon\sim\mathcal N(0,\sigma_i^2)\)，且相互独立，并令 \(u_d(a,\omega_d)=-(a-\omega_d)^2\)。则*
\[
\mathrm{VOI}_i^{(d)}=\sigma_0^2-
\frac{\sigma_0^2\sigma_i^2}{\sigma_0^2+\sigma_i^2}
=\frac{\sigma_0^4}{\sigma_0^2+\sigma_i^2}.
\tag{6}
\]

**证明。** 在平方误差下，最优期望效用为后验方差的负值。高斯条件化给出后验方差 \(\sigma_0^2\sigma_i^2/(\sigma_0^2+\sigma_i^2)\)，它与观测值无关。VOI 为先验方差减去期望后验方差，由此得到 (6)。\(\square\)

此处，新颖度对应精度增益，而信源标定会改变有效噪声。这是一种闭式解释，并非真实决策服从高斯或二次结构的证据。

# 6. 推送过滤：容量、分离度与架构

## 6.1 容量与失真

**命题 6.1（过滤算术）。** *若有 \(N\) 个候选到达，\(\tau_i\geq\underline\tau>0\)，且消费预算为 \(T\)，则任何策略消费 \(m\leq T/\underline\tau\) 个条目，丢弃比例至少为 \(1-T/(\underline\tau N)\)。*

**证明。** 对于消费集 \(A\)，有 \(m\underline\tau\leq\sum_{i\in A}\tau_i\leq T\)。除以 \(N\) 即得丢弃比例。\(\square\)

令 \(E^*\) 包含 \(K^*\) 个关键命题，其价值为 \(v_e\)，并定义泄漏
\[
\mathcal D(\pi)=\mathbb E\!\left[\sum_{e\in E^*}v_e\mathbf 1\{e\text{ not consumed}\}\right].
\]

**命题 6.2（最优失真下界）。** *若预算至多容纳 \(m\) 个不同命题，且 \(V_{(1)}\geq\cdots\geq V_{(K^*)}\) 是价值的递减重排，则*
\[
\mathcal D(\pi)\geq\mathcal D^*
=\mathbb E\!\left[\sum_{r>m}V_{(r)}\right].
\tag{7}
\]
*完美价值排序并将全部预算分配给关键命题可达到等号。*

**证明。** 任何策略至多消费 \(m\) 个关键价值，因此已消费的关键价值至多为 \(\sum_{r\leq m}V_{(r)}\)。从总关键价值中减去该量即得 (7)；选择前 \(m\) 项可达到等号。\(\square\)

若价值独立同分布于 Pareto 分布，其尾部为 \(P(V>v)=(v/v_{\min})^{-\alpha}\)，\(\alpha>1\)，通常的次序统计量积分近似给出
\[
\frac{\mathcal D^*}{\mathbb E[\sum_ev_e]}
\approx1-\left(\frac{m}{K^*}\right)^{(\alpha-1)/\alpha}.
\tag{8}
\]
事实上，前 \(m\) 项之和的期望近似为
\[
K^*v_{\min}\int_0^{m/K^*}u^{-1/\alpha}\,du
=K^*v_{\min}\frac{\alpha}{\alpha-1}(m/K^*)^{(\alpha-1)/\alpha},
\]
而期望总量为 \(K^*v_{\min}\alpha/(\alpha-1)\)。式 (8) 是一阶大样本近似，而非精确的有限样本恒等式；当 \(m\) 或 \(K^*\) 较小时，应使用精确的 gamma 函数次序统计量 [31]。

## 6.2 评分分离度瓶颈

设 \(0<\pi<1\) 为 \(M\) 个命题中关键命题所占的比例，过滤器准入前 \(0<\beta<1\) 的比例，其中 \(\beta=m/M\)。非关键评分为 \(\mu_0+\sigma Z\)，关键评分为 \(\mu_0+d'\sigma+\sigma Z\)，且 \(Z\sim\mathcal N(0,1)\)。令 \(\bar\Phi=1-\Phi\)。

**定理 6.1（预算–分离度–召回恒等式）。**

*(i) 阈值 \(z=(\tau-\mu_0)/\sigma\) 与召回 \(R\) 满足*
\[
(1-\pi)\bar\Phi(z)+\pi\bar\Phi(z-d')=\beta,
\qquad R=\bar\Phi(z-d').
\tag{9}
\]

*(ii) 分布无关的容量上限：* \(R\leq\min\{1,\beta/\pi\}\)。

*(iii) 目标 \(R\) 可行仅当 \(\beta\geq\pi R\)。对于 \(\pi R<\beta<1\)，高斯模型要求以下分离度；边界情形由扩充实数线上的连续性得到：*
\[
d'\geq\underline d'(\beta,\pi,R)=
\Phi^{-1}\!\left(1-\frac{\beta-\pi R}{1-\pi}\right)+\Phi^{-1}(R).
\tag{10}
\]

*(iv) 当 \(\pi=0.01\)、\(\beta=0.0125\)、\(R=0.95\) 时，\(\underline d'\approx4.39\)，且 \(\mathrm{AUC}=\Phi(d'/\sqrt2)\approx0.999\)。*

**证明。** (i) 准入比例是高于 \(\tau\) 的混合分布尾概率，由此得到第一式。以关键性为条件时，标准化阈值为 \(z-d'\)，由此得到第二式。

(ii) 至多准入 \(\beta M\) 个条目。被召回的关键条目既不能超过准入条目数，也不能超过全部 \(\pi M\) 个关键条目，因此 \(R\pi M\leq\min\{\beta M,\pi M\}\)。

(iii) 必要性由 \(\pi R\leq\beta\) 得出。在最小所需 \(d'\) 的等号情形下，(9) 蕴含
\[
\bar\Phi(z)=\frac{\beta-\pi R}{1-\pi},
\qquad
z=\Phi^{-1}\!\left(1-\frac{\beta-\pi R}{1-\pi}\right).
\]
此外，\(R=\bar\Phi(z-d')\) 给出 \(z-d'=-\Phi^{-1}(R)\)。两式相减即得 (10)。

为证明充分性与单调性，定义
\[
F(z,d')=(1-\pi)\bar\Phi(z)+\pi\bar\Phi(z-d')-\beta.
\]
对于每个 \(d'\)，\(F\) 关于 \(z\) 连续且严格递减，因此存在唯一阈值 \(z(d')\)。记正态密度为 \(\varphi\)，隐函数求导给出
\[
\frac{dz}{dd'}=-\frac{F_{d'}}{F_z}
=\frac{\pi\varphi(z-d')}{(1-\pi)\varphi(z)+\pi\varphi(z-d')}\in(0,1).
\]
因而，
\[
\frac{dR}{dd'}=-\varphi(z-d')\left(\frac{dz}{dd'}-1\right)>0.
\]
所以，召回随 \(d'\) 严格增加，而 \(\beta\) 保持固定；每个高于 (10) 中边界的 \(d'\) 都至少达到目标。

(iv) 代入数值得到
\[
\underline d'=\Phi^{-1}(0.99697)+\Phi^{-1}(0.95)
\approx2.74+1.645=4.39.
\]
对于相互独立的关键与非关键评分，其差值的方差为 \(2\sigma^2\)，故 \(\mathrm{AUC}=\Phi(d'/\sqrt2)\)，约为 \(0.999\)。\(\square\)

仅第 (iv) 部分的数值依赖高斯假设。计数上限是分布无关的；重新标定尾部后，可以将另一位置族代入 (9)。评分相关性不改变边际恒等式，尽管重复项挤占仍会浪费名额。

## 6.3 命题坍缩与双通道原理

在文档粒度上，\(\beta_d=m/N\)，\(\pi_d=K^*\bar r/N\)，其中 \(\bar r\) 是关键文档的平均冗余度。因此 \(R_{\mathrm{doc}}\leq m/(K^*\bar r)\)。坍缩后，\(M=N/\rho_c\)，\(\beta_p=\rho_c\beta_d\)。若关键冗余度 \(\bar r\) 与 \(\rho_c\) 相当，则 \(\pi_p\approx\pi_d\)，所以可行性条件 \(\beta\geq\pi R\) 约放宽 \(\rho_c\) 倍。此外，\(\underline d'\) 随 \(\beta\) 增大而减小。坍缩还防止同一命题的多个副本占用多个名额。这些是对容量的改善，而非承诺不完美的评分器能够达到计数上限。

数值上，当 \(m=10\)、\(N=10^4\)、\(\pi_d=0.01\) 时，文档级选择有 \(\beta_d=0.001\)，因而即使评分完美也有 \(R_{\mathrm{doc}}\leq0.1\)。若 \(\rho_c=12.5\)，坍缩后约有 \(M=800\) 个命题，且 \(\beta_p=0.0125\)；当 \(K^*=8\) 时，这正是定理 6.1(iv) 的运行点。因此，坍缩将问题从计数上的不可能转变为苛刻但可分析的分离度要求。

由此形成两个并行通道。

| 通道 | 功能与保证 |
|:---|:---|
| I：保证/直通 | 监测类别与经核验的观察清单条目在去重后绕过竞争性评分；召回来自覆盖结构。 |
| II：发现/评分 | 其余命题竞争剩余名额；召回由 \(\beta,\pi,d'\) 与价值排序共同定价。 |

: 表 3. 双通道获取架构中的分工。

**架构原理。** *当 \(d'<\underline d'(\beta,\pi,R)\) 时，任何纯评分通道都无法达到目标 \(R\)；保证必须来自额外的获取或直通结构。* 这是定理 6.1 的直接推论，并非主张评分没有必要。通道 II 发现未被监测的关键条目，并在预算约束收紧时进行价值排序。

交付前必须进行可行性审计。为简化起见，先忽略公共或紧急预留，期望关键召回 \(R\) 大致要求 \(R\mathbb E|E^*|\leq m\)。计入预留 \(m_{\mathrm{pub}}\) 与 \(m_{\mathrm{slack}}\) 后，必要条件为
\[
R\mathbb E|E^*|\leq m-m_{\mathrm{pub}}-m_{\mathrm{slack}}.
\tag{11}
\]
若违反该条件，就必须增加预算、缩小显式声明的关键集合或降低目标；悄然稀释召回违反 S4。

## 6.4 选择算法与在线阈值

经过硬性伤害筛查后，考虑非负选择目标
\[
U(A)=U_{\mathrm{cov}}(A)+\mu U_{\mathrm{div}}(A),
\]
其中
\[
U_{\mathrm{cov}}(A)=\sum_ev_e\mathbf 1\{A\cap D_e\neq\varnothing\},
\quad
U_{\mathrm{div}}(A)=\sum_{\sigma\in\mathcal S}\max_{i\in A}\mathrm{sim}(\sigma,i),
\]
且 \(\mu,\mathrm{sim}\geq0\)，\(\sum_{i\in A}\tau_i\leq T_{\mathrm{push}}\)。

**定理 6.2（筛查后目标的单调次模性）。** *\(U\) 是单调次模函数。*

**证明。** 添加条目不会移除命题覆盖，也不会降低最大值，因此两项均单调。对于 \(A\subseteq B\) 与 \(i\notin B\)，
\[
U_{\mathrm{cov}}(A\cup i)-U_{\mathrm{cov}}(A)
=\sum_{e:i\in D_e,A\cap D_e=\varnothing}v_e
\geq\sum_{e:i\in D_e,B\cap D_e=\varnothing}v_e
=U_{\mathrm{cov}}(B\cup i)-U_{\mathrm{cov}}(B),
\]
因为 \(B\cap D_e=\varnothing\) 蕴含 \(A\cap D_e=\varnothing\)。对于每个立场 \(\sigma\)，记 \(m_A=\max_{j\in A}\mathrm{sim}(\sigma,j)\)。则 \(m_A\leq m_B\)，边际增益之差为
\[
(\mathrm{sim}(\sigma,i)-m_A)^+-(\mathrm{sim}(\sigma,i)-m_B)^+\geq0.
\]
对立场求和并加上覆盖项后，不等式仍然成立。\(\square\)

**命题 6.3（经典贪心选择保证）。** *对于定理 6.2 中筛查后的单调次模目标，基数约束贪心达到最优值的 \(1-1/e\)。成本不等时，密度贪心与最佳单元素解中的较优者达到 \(\tfrac12(1-1/e)\)；部分枚举加密度贪心达到 \(1-1/e\)。*

**证明。** 这些结果是经典基数约束、背包密度与部分枚举保证的直接应用 [27–30]，带预算最大覆盖是其特例 [29]。定理 6.2 验证了这些结果所需的目标结构。它们仅保证这一选择子问题，而非联合 SAP。\(\square\)

对于在线到达，令 \(W_i(b)\) 表示还剩 \(i\) 期与 \(b\) 个等成本名额时的最优后续价值。评分为 \(s\sim F\) 的条目产生递增且连续的奖励 \(r(s)\)。

**命题 6.4（阈值最优性）。** *贝尔曼方程与最优决策为*
\[
W_i(b)=\mathbb E_s\max\{r(s)+W_{i-1}(b-1),W_{i-1}(b)\},
\]
\[
\text{consume iff }r(s)\geq\tau_i(b):=W_{i-1}(b)-W_{i-1}(b-1).
\]
*\(W_i\) 关于 \(b\) 为凹函数，因此阈值随剩余名额增加而不增，随剩余期数增加而不减。*

**证明。** 贝尔曼方程比较消费与丢弃；整理后立即得到阈值。令 \(\Delta_i(b)=W_i(b)-W_i(b-1)\)，\(g(\tau)=\mathbb E[(r(s)-\tau)^+]\)。则
\[
W_i(b)=W_{i-1}(b)+g(\Delta_{i-1}(b)),
\]
所以
\[
\Delta_i(b)=\Delta_{i-1}(b)+g(\Delta_{i-1}(b))-g(\Delta_{i-1}(b-1)).
\tag{12}
\]
函数 \(g\) 非负、不增且为 1-Lipschitz，因为 \(t\mapsto(c-t)^+\) 逐点具有这些性质。归纳假设 \(\Delta_{i-1}\) 不增，并设
\[
x=\Delta_{i-1}(b-2)\geq y=\Delta_{i-1}(b-1)\geq z=\Delta_{i-1}(b).
\]
式 (12) 蕴含
\[
\Delta_i(b-1)-\Delta_i(b)
=(y-z)+[g(y)-g(x)]+[g(y)-g(z)].
\]
单调性给出 \(g(y)-g(x)\geq0\)；1-Lipschitz 连续性给出 \((y-z)+g(y)-g(z)\geq0\)。因此，\(\Delta_i\) 不增，且递推从 \(\Delta_0=0\) 开始。同一递归还给出 \(\Delta_i(b)\geq\Delta_{i-1}(b)\geq0\)，从而证明所述两项阈值单调性。\(\square\)

阈值是一个名额的机会成本。第 8 节在可分凹分配模型下，将其等同于共同的注意力影子价格。

# 7. 冗余覆盖与条件性召回保证

## 7.1 假设与独立子集界

通道 I 使用三项假设。

- **R1 覆盖下界：** 对于每个相关关键命题 \(e\) 与监测类别 \(i\)，有 \(P(Z_i(e)=1)\geq p_{\min}\)。
- **R2 条件独立：** 给定关键性，各类别的覆盖事件相互独立。
- **R3 直通：** 经核验的显式观察清单实体内容绕过评分，去重后到达，并受预算可行性警报约束。

**定理 7.1（独立冗余覆盖）。** *在 R1–R2 下，从 \(k\) 个监测类别直接直通，对于每个关键命题 \(e\) 给出*
\[
P(\mathrm{miss}\,e)\leq(1-p_{\min})^k.
\tag{13}
\]

**证明。** 只有当所有监测类别都未覆盖 \(e\) 时，才会发生过滤漏报。因此
\[
P(\mathrm{miss}\,e)=P\!\left(\bigcap_{i=1}^k\{Z_i(e)=0\}\right)
=\prod_iP(Z_i(e)=0)\leq(1-p_{\min})^k.
\]
等号使用 R2，不等号使用 R1。\(\square\)

例如，\(p_{\min}=0.7,k=5\) 给出漏报上界 \(0.00243\)。这一算术仅为示意：R1 是对每个关键命题普遍成立的假设，而非估计的平均报道率。

为处理任意依赖，称 \(S\) 为 \(e\)-独立集，如果 \(\{Z_i(e)\}_{i\in S}\) 相互独立，并定义
\[
k_{\mathrm{eff}}(e)=\max\{|S|:S\text{ is }e\text{-independent}\},
\qquad k_{\mathrm{eff}}=\min_{e\in E^*}k_{\mathrm{eff}}(e).
\]

**定理 7.2（相关情形覆盖）。** *仅在 R1 下，*
\[
P(\mathrm{miss}\,e)\leq(1-p_{\min})^{k_{\mathrm{eff}}(e)}
\leq(1-p_{\min})^{k_{\mathrm{eff}}}.
\tag{14}
\]

**证明。** 选取最大的 \(e\)-独立集 \(S^*\)。所有 \(k\) 个类别都失败，蕴含 \(S^*\) 中所有类别都失败。由事件包含、\(S^*\) 上的独立性与 R1 得
\[
P(\mathrm{miss}\,e)\leq P\!\left(\bigcap_{i\in S^*}\{Z_i(e)=0\}\right)
=\prod_{i\in S^*}P(Z_i(e)=0)
\leq(1-p_{\min})^{|S^*|}.
\]
第二个不等号成立，因为 \(k_{\mathrm{eff}}(e)\geq k_{\mathrm{eff}}\) 且 \(1-p_{\min}\in[0,1]\)。\(\square\)

**命题 7.1（紧性）。** *对于每个 \(0<p_{\min}<1\) 与可行的 \(k_{\mathrm{eff}}\)，若没有额外的依赖假设，(14) 无法被一致地改进。*

**证明。** 将类别划分为 \(k_{\mathrm{eff}}\) 个非空组。在每组内，令每个 \(Z_i\) 都等于同一个伯努利\((p_{\min})\) 变量；令组变量相互独立。此时 R1 成立，同组任意两个不同类别均不独立，最大独立子集从每组各取一个类别。所有类别失败当且仅当所有组变量失败，该事件的概率为 \((1-p_{\min})^{k_{\mathrm{eff}}}\)。\(\square\)

其工程启示有限但有用：考虑所有权与上游依赖的类别设计可以提高可辩护的 \(k_{\mathrm{eff}}\)。两两相关阈值只是诊断工具，并非相互独立性的证明。虚假草根造势专门通过制造具有共同根源但名义上独立的信源来攻击这一结构。

## 7.2 观察清单、监测分配与总召回

**命题 7.2（观察清单过滤保证）。** *在 R3 下，若经核验的观察清单实体发布了关于 \(e\) 的内容，且直通预算可行，则过滤阶段的漏报概率为零。*

**证明。** R3 使条目在溯源核验与去重后确定性地准入。任何评分阈值都无法拒绝该条目。该保证不涵盖上游沉默、绕过核验的冒充以及不可行的直通配额；最后一种情形必须触发警报，而非悄然丢失。\(\square\)

对于已知类别，令 \(p_i(e)=P(Z_i(e)=1)\)、\(w_e\geq0\)，并定义
\[
U_{\mathrm{mon}}(S)=\sum_ew_e\left(1-\prod_{i\in S}(1-p_i(e))\right).
\tag{15}
\]
该乘积形式假设 R2 成立。

**定理 7.3（监测次模性）。** *在 R2 下，\(U_{\mathrm{mon}}\) 是单调次模函数；经典基数约束与背包贪心保证适用。*

**证明。** 单调性成立，因为添加类别只会减小非覆盖概率的乘积。固定 \(e\)，记 \(q_i=1-p_i(e)\in[0,1]\)，\(f_e(S)=1-\prod_{i\in S}q_i\)。对于 \(A\subseteq B\) 与 \(j\notin B\)，
\[
f_e(A\cup j)-f_e(A)=(1-q_j)\prod_{i\in A}q_i
\geq(1-q_j)\prod_{i\in B}q_i
=f_e(B\cup j)-f_e(B),
\]
因为 \(0\leq q_i\leq1\)。对 \(e\) 作非负求和仍保持次模性。近似保证则是标准推论 [27–30]。\(\square\)

在跨类正相关下，(15) 可能高估覆盖。此时，优化应使用可辩护的独立组或直接估计的联合覆盖，而不能假装独立公式仍然精确。

最后，对于非观察清单命题，令 \(R_{\mathrm{II}}=P(\text{Channel II recovers }e\mid\text{Channel I fails})\)。

**定理 7.4（双通道过滤漏报界）。** *在 R1 与 R3 下，对于非观察清单命题 \(e\)，*
\[
P(\mathrm{miss}\,e)\leq(1-p_{\min})^{k_{\mathrm{eff}}}(1-R_{\mathrm{II}}),
\tag{16}
\]
*因而 \(P(\mathrm{miss}\,e)\leq(1-p_{\min})^{k_{\mathrm{eff}}}\)。根据命题 7.2，经核验且可行的观察清单直通在过滤阶段的漏报为零。*

**证明。** 发生漏报要求两个通道都失败。链式法则给出
\[
P(\mathrm{miss})=P(\mathrm{I\ fails})P(\mathrm{II\ fails}\mid\mathrm{I\ fails})
=P(\mathrm{I\ fails})(1-R_{\mathrm{II}}).
\]
定理 7.2 给出第一个因子的上界，从而证明 (16)。这里不假设两个通道相互独立。去掉 \(1-R_{\mathrm{II}}\leq1\) 即得无条件上界。\(\square\)

\(R_{\mathrm{II}}\) 项以一个经过选择且较困难的子集为条件：通道 I 失败的命题可能冗余度低、可观测特征弱。通常不能用定理 6.1 中评分器的无条件召回来替代它。因此，除非测得条件补获率，定理层面的部署应依赖最后那个较粗的上界。

## 7.3 适用域

有三条边界至关重要。第一，\(p_{\min}\) 部分地是一个**设计变量**：清单粒度与容量可以显著改变它。第二，它可以具有**制度来源**，例如强制性一手信源披露，但这种来源由制度提供，而非由 SEA 提供。第三，配额匹配是保证的一部分：若准入供给超过预留容量，且超额条目被悄然丢弃，直接直通就无法保护召回。

因此，“95% 关键召回”不是该架构的普遍性质。它是一个条件性目标，要求：(i) 在声明的 \(E^*\) 上具有可辩护的覆盖下界；(ii) 足够的有效独立性；(iii) 配额可行；(iv) 决策集与认知预算相容。低冗余、未声明、非公共且评分器不可见的命题仍是不可约的审计类别。

# 8. 拉取获取与注意力无套利

## 8.1 拉取算子与共同影子价格

主动获取包括：**探索**，以成本 \(c_e\) 对未知信源抽样；**查询**，检索观测 \(Y_q\)，其与 \(D\) 相关，成本为 \(c_q\)；以及**停留**，在信源中花费时间 \(t\)，其累积价值为 \(G_s(t)\)。这些操作改变候选池，而非仅对外生信息流排序。

在分配定理中，将 \(T\) 分配给用途 \(u\)，包括推送、拉取操作与反思。用途 \(u\) 获得 \(x_u\geq0\) 分钟，并产生 \(V_u(x_u)\)。假设 **A1（凹性）：** 每个 \(V_u\) 均递增、为凹函数、连续可微，并在最优点非餍足；**A2（可分离性）：** \(V(x)=\sum_uV_u(x_u)\)。可分离性是一种理想化，因为检索会改变推送新颖度，反思也会改变二者。

**定理 8.1（注意力无套利；统一定理）。** *在 A1–A2 下，\(x^*\) 满足 \(\sum_ux_u^*=T\) 且为最优，当且仅当存在某个 \(\nu>0\) 使得*
\[
V_u'(x_u^*)=\nu\quad(x_u^*>0),
\qquad
V_u'(0)\leq\nu\quad(x_u^*=0).
\tag{17}
\]

**证明。** 必要性部分，设两个内点用途满足 \(V_u'(x_u^*)>V_{u'}'(x_{u'}^*)\)。将 \(\epsilon>0\) 分钟从 \(u'\) 转移到 \(u\)。当 \(\epsilon\) 足够小时，可行性保持不变，而可微性给出
\[
V(x')-V(x^*)=\epsilon(V_u'(x_u^*)-V_{u'}'(x_{u'}^*))+o(\epsilon)>0,
\]
与最优性矛盾。若某个未启用用途的导数高于启用用途的共同边际价值，将少量预算转入该用途也会产生同样的矛盾。

充分性部分，由凹性得
\[
V_u(x_u)\leq V_u(x_u^*)+V_u'(x_u^*)(x_u-x_u^*).
\]
对于任何可行的 \(x\)，对 \(u\) 求和。启用用途的导数等于 \(\nu\)；在未启用的角点处，\(V_u'(0)(x_u-x_u^*)=V_u'(0)x_u\leq\nu x_u\)。因此
\[
V(x)-V(x^*)\leq\nu\sum_u(x_u-x_u^*)=\nu(T-T)=0.
\]
故 \(x^*\) 全局最优。由非餍足性可知预算会被用尽。\(\square\)

其数学内容是凹问题的 KKT 变分原理。其统一性体现在实例清单：同一个 \(\nu\) 是推送机会阈值、探索与查询投入的停止比较基准、补丁离开率、监测名额机会成本以及反思时间的价格。Pandora 规则与边际价值规则是经典特例 [10,11]，而非本文主张的新推论。

## 8.2 探索与停留

对于相互独立的 Pandora 盒，盒 \(i\) 具有随机奖励 \(X_i\sim F_i\)、以效用单位计的检查成本 \(c_i\)，以及保留指数
\[
\mathbb E[(X_i-z_i)^+]=c_i.
\tag{18}
\]
左端连续，并从任意大的值严格递减至零，因此在通常的支撑集条件下存在唯一指数。Weitzman 的最优规则按指数降序开盒，并在最佳已实现奖励超过所有剩余指数时停止 [10]。

**命题 8.1（信源探索与监测准入）。** *令探索成本 \(c_e^{\mathrm{time}}\) 通过 \(c_e=\nu c_e^{\mathrm{time}}\) 转换为效用。当候选信源的保留指数超过最佳外部选择奖励时，才值得探索；只有当已揭示的信源价值超过被挤占名额的机会价值时，才证明监测合理。在单位视界归一化下，二者均记为 \(\nu\)，上述条件分别为探索的 \(z_s\geq\nu\) 与准入的 \(X_s\geq\nu\)。*

**证明。** 添加一个奖励为 \(b\) 的确定性外部选择盒。当检查成本 \(c>0\) 时，(18) 给出其指数 \(z_c=b-c\)；因此，零成本极限赋予其保留价值 \(b\)。在成本恰好为零时，仅由正部方程会得到一个平坦零值区域，无法确定唯一指数，因此需要这一极限（或直接定义外部选择的保留价值）。于是，Weitzman 规则不会开启任何 \(z_s<b\) 的盒子，也不会接受任何低于 \(b\) 的已揭示奖励。对于监测，相关外部选择是被占用名额所挤出的价值；若估计价值持续低于它，就触发轮换复核。将 \(b\) 与名额机会价值归一化为 \(\nu\)，即得所示判据。\(\square\)

单位视界记号不应掩盖量纲：一般而言，必须通过影子价格与共同监测视界对分钟进行转换。监测准入还必须尊重边际覆盖与配额可行性；一个 VOI 很高但完全冗余的信源，其增量价值可能低于 (18) 所显示的水平。

对于停留，令 \(G_s(t)\) 递增且为凹函数，并令 \(c_{\mathrm{sw}}\) 表示**效用等价**的切换成本（若切换耗时 \(t_{\mathrm{sw}}\) 分钟，则 \(c_{\mathrm{sw}}=\nu t_{\mathrm{sw}}\)）。平均摄入率为
\[
R_s(t)=\frac{G_s(t)-c_{\mathrm{sw}}}{t}.
\]

**命题 8.2（边际价值停留规则）。** *在内点最优 \(t^*\) 处，*
\[
G_s'(t^*)=R_s(t^*)
\quad\Longleftrightarrow\quad
G_s'(t^*)t^*=G_s(t^*)-c_{\mathrm{sw}},
\tag{19}
\]
*且跨补丁均衡满足 \(R_s(t^*)=\nu\)。*

**证明。** 求导得到
\[
R_s'(t)=\frac{G_s'(t)t-[G_s(t)-c_{\mathrm{sw}}]}{t^2}.
\]
令分子为零即得 (19)。凹性使 \(G_s'\) 不增、\(G_s(t)-tG_s'(t)\) 不减，因此当内点解存在时，驻点就是全局最大点；否则最优位于边界，包括不进入或无限期停留。若另一活跃用途的边际价值为 \(\nu<R_s(t^*)\)，则将时间重新分配给该补丁是有利可图的，直至恢复定理 8.1 的等式。\(\square\)

## 8.3 查询批次与期望信息增益

令 \(Q\) 为查询批次，\(Y_Q\) 为其观测。定义 \(I(Q)=I(Y_Q;\omega\mid K)\)，即在当前知识下关于决策相关状态的期望信息增益。

**定理 8.2（EIG 结构）。** *(i) \(I(Q)\) 单调。(ii) 若各 \(Y_q\) 在给定 \((\omega,K)\) 时条件独立，则 \(I(Q)\) 为次模函数。(iii) 因此，等成本贪心达到 \(1-1/e\)；有成本约束时，密度贪心/最佳单元素规则达到 \(\tfrac12(1-1/e)\)，部分枚举恢复 \(1-1/e\)。*

**证明。** 由链式法则与条件互信息的非负性，
\[
I(Q\cup q)-I(Q)=I(Y_q;\omega\mid Y_Q,K)\geq0,
\]
这证明了单调性。在给定 \((\omega,K)\) 的条件独立下，
\[
\Delta(Q,q)=I(Y_q;\omega\mid Y_Q,K)
=H(Y_q\mid Y_Q,K)-H(Y_q\mid\omega,K).
\]
对于 \(Q'\subseteq Q\)，以更多观测为条件不会增加熵：
\[
H(Y_q\mid Y_Q,K)\leq H(Y_q\mid Y_{Q'},K).
\]
减去的项不变，因此 \(\Delta(Q,q)\leq\Delta(Q',q)\)，这就是次模性的边际收益递减定义。随后，第 (iii) 部分由经典保证得到 [27–30]。\(\square\)

原始互信息并不自动等于决策价值。当决策相关状态与效用加权能够提供依据时，它是合适的查询代理；否则，应按决策加权期望 VOI 对查询排序。次模性也无法在任意观测依赖下保持。这些限定对横向阅读很重要：当可信度不确定性占主导时，打开独立信源调查溯源可能具有很高边际价值 [34]，但近重复查询的收益可能高度耦合。

当未读信源持续演化时，持续监测是一个不安定 bandit 问题 [22]。Whittle 型指数是有用的启发式，其渐近结果仅在各自条件下成立 [32]；Gittins 最优性适用于限制更强的冻结臂 bandit [21]。这是不能从局部指数规则推断全局 SAP 近似比的又一原因。

最后，当注意力成本以 Shannon 量为基础时，理性疏忽产生软选择而非硬选择 [13–15,33]。在静态离散选择简化下，
\[
P(i\in A)\propto\pi_i^0\exp(\langle w,\phi_i\rangle/\lambda).
\]
这是理性疏忽结果的一个引用特例 [15]，并非本文的新定理。当注意力相对于效用差异变得低廉时，会出现硬阈值。SAP 为 \(w\) 增加了明确的所有者，而非假设目标固定且为外部所知。

# 9. 精选扩展：目标俘获与防火墙界

目标俘获说明 S2 为何必须同时约束检索与过滤。对抗条目可能试图将有效评分权重从 \(w\) 未经授权地改为 \(w+\Delta(x)\)。在线性评分部分，定义
\[
D(\widetilde U,U)=\sup_{x'\in X}|\langle\Delta,\phi_{x'}\rangle|
\leq\|\Delta\|_1,
\tag{20}
\]
因为 \(\phi\in[0,1]^5\)。该度量不能捕捉所有集合层面或世界观变化；较小的 \(D\) 也不是完整的安全证明。AI 实例包括经检索内容实施的间接提示注入 [35,36]，以及赞同驱动的谄媚漂移 [37]。人类情绪俘获的解释是待检验假设，而非本文已经确立的人类效应。

我们使用三项假设：**F1**，每个泄漏条目均满足 \(\|\Delta(x)\|_1\leq\delta\)；**F2**，每个操纵性条目均以概率 \(\rho_m\) 被独立检出；**F3**，可疑类别准入量满足 \(n_m\leq n_{\max}\)。

**定理 9.1（期望防火墙界）。** *在 F1–F3 下，*
\[
\mathbb E[D(\widetilde U,U)]
\leq\delta(1-\rho_m)\mathbb E[n_m]
\leq\delta(1-\rho_m)n_{\max}.
\tag{21}
\]

**证明。** 若 \(L\) 为泄漏集，则由三角不等式与 F1 得 \(D\leq\|\sum_{i\in L}\Delta(x_i)\|_1\leq\delta|L|\)。F2 下的独立检测给出 \(\mathbb E|L|=(1-\rho_m)\mathbb E[n_m]\)。F3 给出最终期望的上界。\(\square\)

**定理 9.2（条件高概率防火墙界）。** *在 F1–F3 下，以 \(n_m\) 为条件，对于任意 \(\beta\in(0,1)\)，以至少 \(1-\beta\) 的概率有*
\[
D(\widetilde U,U)\leq
\delta(1-\rho_m)n_m+
\delta\sqrt{\tfrac12n_m\ln(1/\beta)}.
\tag{22}
\]
*将 \(n_m\) 替换为 \(n_{\max}\)，即得无条件的暴露上限形式。*

**证明。** 若 \(n_m=0\)，则 \(D=0\)，该界平凡成立。否则，给定 \(n_m\)，\(|L|=\sum_{i=1}^{n_m}B_i\)，其中各 \(B_i\sim\mathrm{Bernoulli}(1-\rho_m)\) 相互独立。Hoeffding 不等式 [38] 给出
\[
P(|L|-\mathbb E|L|\geq u\mid n_m)\leq e^{-2u^2/n_m}.
\]
取 \(u=\sqrt{n_m\ln(1/\beta)/2}\)。在对立事件上，将 \(|L|\) 乘以 \(\delta\)，并使用 \(D\leq\delta|L|\)。右端随 \(n_m\) 增加而增大，因此 F3 给出无条件形式。\(\square\)

设计规则是选择检测召回、阈值与 \(n_{\max}\)，使该界低于声明容差。通过集中项，暴露上限在平均检测器性能之外仍独立发挥作用。协同载荷可能使检测错误相关；本文不主张相应的高概率界。载荷簇上限与实测聚合泄漏是缓解措施，不能替代缺失的依赖情形定理。重复暴露现象 [39] 进一步支持去重，而纠正文献 [40,41] 支持保留事后补救作为第二道防线。

# 10. 作为验证与边界映射的证据

## 10.1 证据状态

实证材料具有三项有意限定的作用：检验实测评分分离度是否接近理论要求，估计覆盖假设何时成立，以及检验判断层能否跨模型家族复现机制增益。已完成的证据包括两项真实语料时序重放试点与一项四家族 LLM 智能体判断层重放。完整的群体级 P1–P12 测试组合**仍在进行中**，其预注册运行目标尚未达到。直接端到端 LLM、RAG 安全与福利优化基线臂仍处于设计阶段，本文不报告其结果。

所报告的 SEA 验证未收集或分析任何人类被试数据。HP-0 为**[已设计；数据收集待完成]**，关注可行性而非效能。研究计划其他部分使用的公开人类数据资源是转移锚点，而非 SEA 的人类验证。因此，关于人类德性收敛、反噬防护、校准改善或去技能化防护的所有陈述均为可证伪预测，而非研究发现。

## 10.2 双域重放：召回主张在何处成立、在何处失败

两项试点均使用已冻结的时序重放与事后真值代理。学术域关键性以后续被引 top-2% 的论文为代理；金融市场关键性以已实现的市场移动日为代理。这两种代理均不等同于事前决策关键性。金融重放还使用法定重大披露作为第二种由制度定义的真值。

| 指标 | 学术域试点 | 金融域试点 |
|:---|:---|:---|
| 语料 | arXiv，2019-09 | EDGAR 加公开新闻 |
| 规模 | 2,576 个命题；\(K^*=52\) | 1,876 个命题；15,368 篇文档 |
| 评分 \(d'\) | 0.73–0.77 | 法定 2.65–3.49；市场 0.54–0.60 |
| 覆盖 \(\hat p_{\min}\) | 作者清单约 0.02；机构清单 0.17–0.37 | 法定 1.00；市场 0.70–0.73 |
| 召回边界 | 最佳端到端 0.28 | 组合内、配额匹配 0.952；新闻扩展后 0.910 |

: 表 4. 已冻结的双域试点口径与适用域边界。

学术域高召回的强形式被**拒绝**：其最佳端到端召回为 0.28。不能通过宣称真值不完美来修复这一结果。引用计数存在滞后并对声望敏感，但原始试点报告的敏感性分析并未逆转这一拒绝结论。单信源学术生态还具有 \(\hat\rho_c=1.0\)，因此并未检验多信源坍缩机制。

金融域数值 0.952 的解释范围要窄得多。它是在 \(m=5\) 时，针对事后市场移动日代理，在有利供给条件下取得的**组合内、配额匹配**召回：25 个直通持仓，每日约 4.6 个命题。它不是一般金融召回，不是事前关键信息召回，也不是无条件架构保证。新闻层扩展通过从清单分走配额，使同一设置稀释至 0.910。监管类别在法定真值上的覆盖下界说明了制度来源；它并不表明任意观察清单都具有 \(p_{\min}=1\)。

两个域的实测 \(d'\) 均低于代表性的 4.39 要求。这支持瓶颈的实际相关性，但并非对代数恒等式的独立证明。所报告的高斯拟合相关系数涉及分布近似，而非定理真理性。两项试点共同支持一种域条件性结论：当覆盖、容量与范围一致时，结构可以达到高召回目标；而跨域通用的强主张则不成立。

## 10.3 四家族判断层重放

已完成的学术域机制重放使用四个模型家族、80 次独立运行与 73,547 条有效智能体日记录。主要家族 O 和 C 各贡献 30 次运行；锚定家族 Q 和 G 各贡献 10 次。名义运行模板采用 30 个智能体、30 个模拟日，并采用分片执行以及按协议进行的重试/回填；每个被接受的运行均通过**至少** 900 条有效记录的完整性门槛，该门槛是最低要求而非上限。召回比较将判断层与诚实特征臂相对照；另一次按日配对的比较使用半 oracle 参数臂。两项比较均不验证端到端 SAP 或人类行为。

| 家族 | 关键召回 | 运行自助法 95% 置信区间 | \(\Delta\)价值 |
|:---|---:|:---|---:|
| O | 0.443 | [0.433, 0.454] | −0.175 |
| C | 0.534 | [0.527, 0.541] | +0.676 |
| Q | 0.514 | [0.502, 0.526] | +0.432 |
| G | 0.519 | [0.498, 0.539] | −0.223 |

: 表 5. 四家族判断层结果；区间为运行层自助法 95% 置信区间。

诚实特征臂的召回为 0.241。每个判断家族的召回均至少为其 1.8 倍，但半 oracle 比较中的价值增量出现分化：C 与 Q 为正，O 与 G 为负。因此，召回改善不能概括为一致的价值改善。这种不一致本身是一项结果与一个开放机制问题，而非可以通过平均化抹去的异常。

智能体日是测量单位，但运行是独立重复单位。置信区间采用运行层自助重抽样，汇总推断在 80 个层中按运行分层。对于上述按日配对的判断臂对半 oracle 比较，跨家族连续性校正 CMH 统计量为 \(\chi^2_1=981.5\)。其渐近上尾计算为
\[
p=\operatorname{erfc}\!\left(\sqrt{\chi^2/2}\right)
\approx1.9\times10^{-215}.
\]
这一极端 \(p\) 值**仅用于数量级定向**，而非经校准的错误概率。效应量、家族特异置信区间与按运行分层的重复才是推断依据。作废协议与被剔除家族均被隔离，而非悄然纳入分析。

## 10.4 证伪映射

该理论还产生了超出已完成试点的检验。

| 机制 | 预测 | 失败解释 |
|:---|:---|:---|
| 评分瓶颈 | 实测阈值尾部满足相应的类别条件恒等式。 | 重新标定分布或拒绝评分器模型。 |
| 覆盖 | 漏报保持在经置信度调整的覆盖界以下。 | R1、独立性或类别估计失败。 |
| 无套利调度 | 在匹配预算下，向较高边际 VOI 再分配可提高价值。 | 可分离性或边际价值估计失败。 |
| EIG 查询批次 | 贪心接近相应的次模基准。 | 条件独立或价值代理失败。 |
| 防火墙 | 暴露遵循相应的期望界或集中界。 | F1–F3 或其标定失败。 |

: 表 6. 主要理论机制的证伪映射。

结构性覆盖与评分召回同时失败，将拒绝核心激进过滤计划。相比之下，某项人类行为预测的失败将拒绝相应的人类实例化，而不会改变覆盖或预算定理的代数关系。

# 11. 讨论

## 11.1 综合框架带来的改变

SEA 将获取重新表述为在所有权约束下对候选池及其选择的控制。监测清单不仅是偏好清单：它决定哪些覆盖事件能够保证召回。查询不仅是一次交互：它改变未来供给并消耗当前注意力。反思也不是开销：它在保留测量与授权通道的同时，以影子价格 \(\nu\) 参与竞争。这些是同一预算约束问题中的不同操作。

该理论还比“使用更好的模型”更明确地划分了责任。评分器负责发现与排序，其误差由类别条件分离度测量。命题坍缩负责名额效率。信源构建与主动监测负责覆盖。直通配额负责可行性。S2 与 S4 负责防止并检测未经授权的目标写入。因此，失败可以被定位，而不会不加区分地促使模型扩大。

最小实现遵循同一逻辑：声明 \(D,g^{(2)},T\) 与观察清单；构建具有溯源的命题图；按信源类别估计覆盖；预留并审计通道 I 的容量；仅对剩余发现池评分；估计推送、拉取与反思之间的边际 VOI；并记录每次写入与准入。这些步骤都不预设普通用户能够陈述完整的效用函数。效用引出仍是重大的未解决负担；协作式目标学习与可纠正性提供了相关工具 [53,54]，但 SEA 要求人类授权，而不是自动固化推断出的偏好。

## 11.2 局限与开放问题

主要局限与定理假设直接对应。

1. **价值表征。** 除单独的慢变项外，V1 排除了不经声明决策中介的价值。V4 很强，且线性评分对 (4) 没有一般近似保证。决策集遗漏可能使召回审计内部一致，却在外部意义上错误。
2. **评分模型。** 容量上限具有一般性，但 \(4.39\) 依赖高斯假设与特定运行点。重尾或偏斜评分需要经验尾部。估计 \(\pi,\beta,d'\) 还会引入点计算未捕捉的不确定性。
3. **覆盖。** R1 必须对声明关键范围内的每个命题成立，而非仅平均成立。在共享上游下，R2 常常不合理。定理 7.2 仅通过有保证的独立子集为依赖定价；从有限语料估计相互独立性仍然困难。上游沉默不在任何过滤保证之内。
4. **预算分配。** 定理 8.1 假设可分离的凹价值函数。查询结果与推送新颖度之间的互补性可能违反 A2。Pandora 与平稳补丁模型在信源漂移下也会退化。Whittle 调度在其渐近与可索引性条件之外是启发式的。
5. **查询价值与计算。** 条件独立对于定理 8.2(ii) 至关重要。互信息的估计成本可能很高，而且不必跟踪效用。贪心比率针对形式目标，而非估计误差或端到端流水线。
6. **对抗漂移。** F1 的单条目影响有界与 F2 的独立检测都是经验标定负担。协同攻击会使目前的集中论证失效，而线性评分偏离度量并未穷尽信念或目标转变。
7. **主权与治理。** 反思性认可本身也可能是适应性的 [51]。默认项负载价值，即使有审计日志，Goodhart 式指标俘获仍可能发生 [52]。主权工具可用于构建封闭回音室，而公平可及性无法仅靠个体优化解决。
8. **组合与扩展。** 局部比率与界并不能产生分层 SAP 的全局近似比。本文核心不需要公共议程、紧急覆盖与长视界德性机制，也不对这些机制作出主张。特别是，源框架的**猜想 10.1（条件性、正漂移下界分支）仍未获证** [55]；本文既不证明它，也不将其改作定理使用。本文不提出任何人类门控收敛主张。

这些局限也标明了验证与确认之间的差别。LLM 智能体队列可以检验载体中立的计算与 AI 实例化，但家族特异性校准与说服反应会限制迁移。人类锚点以及关于对立暴露 [42]、算法信息流 [45,46] 和纠正 [40,41] 的研究为假设提供依据；它们不能替代受控人类评估。适当的下一步实证工作是在提出更广泛的比较主张之前，完成既定范围的基线与完整 P1–P12 设计。

## 11.3 伦理与审计要求

同一架构也会产生双重用途风险。用户控制的过滤器可以保护注意力，也可以加剧隔离；溯源可以支持问责，也可以排除制度记录较薄弱的边缘化信源。开放实现、可导出日志、可逆设置以及对原始信源的访问能够缓解但不能消除这些风险。审计应包括按群体统计的信源覆盖、配额失败，以及由谁承担声明与反思成本。

人类批准必须是实质性的，而非仪式性点击。审核者需要能够访问底层证据、拥有充足时间，并真正有能力拒绝变更。系统输出不应享有可信度豁免：生成的摘要与评判应与外部内容一样，进入相同的溯源与校准过程。这些要求源于 S1–S4，比简单添加一个泛泛的“人类在环”标签更为重要。

# 12. 结论

主权获取问题在一个认知预算与智能体拥有的目标下，统一了主动获取与被动过滤。其核心理论启示是一种分工。评分为发现定价，但极端过滤使纯评分召回要求变得明确且常常无法达到。命题坍缩节省名额，监测冗余与经核验直通提供条件性覆盖保证。随后，主动探索、查询批次、停留与反思通过共同的注意力影子价格与推送消费进行定价。

这些保证被有意设为条件性的。覆盖取决于可辩护的 \(p_{\min}\)、有效独立性与配额可行性；EIG 次模性取决于条件独立；无套利取决于可分凹性；防火墙集中界取决于独立检测。试点映射了这些边界：学术域强形式召回在 0.28 处失败，而有利的金融组合内召回达到 0.952，随后稀释至 0.910。四家族重放复现了召回增益，却未复现一致的价值增益。两类证据都不是人类效能证据，也都不能提供全局 SAP 近似比。因此，本文的贡献不是一个已经解决的普适过滤器，而是一种可检验的架构，使所有权、获取、召回与注意力成本能够得到共同分析。
