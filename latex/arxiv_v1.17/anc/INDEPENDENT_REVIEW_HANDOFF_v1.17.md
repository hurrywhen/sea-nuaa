| B3 切换、重置与评价队列 | `switch_after_period=k` 是否在完成 `0,…,k` 后、`k+1` 期运行前切换，旧路径能否越过；旧队列是否不被追溯改标；连续性共享时钟与完全重置从 0 开始是否一致；reset 白名单之外是否另冻结触发／时机／确定性选目规则，否则是否仅列探索性；跨版本不合并及按版本冻结 \(\nu^{(v)}\) 是否落实。 |  |
| B4 公式（6）及 sharp 性 | 从每臂 `M_FC-M_Z=Σ_{unknown}ν·1{Z=1}` 推导区间；检查两个端点的臂别赋值能否同时实现；确认加权、全分配和 unknown 编码没有改变 sharp 性，且该结论不扩展到潜在真实消费。 |  |
| B5 S12 识别恒等式与可行域 | 从 `q=se·π+(1-sp)(1-π)` 独立重推；核查 `se+sp>1`、`1-se≤mZ≤sp`、仅 completed measurements、验证→部署条件稳定性和 unknown 另行处理；区分 `J=0,N=0` 不识别、`J=0,N≠0` 不相容及 plug-in 越界的抽样不稳定，且不可静默截断。 |  |
| B6 delta method 与 PSD | 独立重算三个偏导、`J⁻¹(1-f,-f,1)` 等价梯度和六项展开，确认一阶近似而非精确方差；检查零方差行、全部归一化二阶／三阶主子式与最终标量方差；构造至少一个联合非 PSD 反例。明确 PSD 仅是容差内的代数合法性、零协方差不推出独立，也不是精确算术证书、估计准确性或区间覆盖率证明。 |  |
| B7 近零 Youden 分母与重抽范围 | 检查 `J→0` 时不稳定性、`1/J²` 仅作公共尺度及 `N/J` 变化时可能更高阶；核查精度阈值与敏感性网格。确认助手只联合重估 `se,sp`、固定 `mZ`，同样本三输入需真正三重抽或全协方差；百分位区间条件于非退化 replicate，高退化比例／少 clusters 时不得称自动校准。 |  |
| B8 零完成与单类／缺失层 | 检查完成率、`0/0` 份额、sensitivity／specificity 分母、单层异质性、缺失 stratum 和 unknown 的 `None/not_estimable` 定义；确认没有把不可估计改写为零。 |  |
| B9 Wilson 区间边界 | 独立核对公式与 `n=0,0/n,n/n`；核查单位级、非聚类调整、非同时区间限定，以及分层／多臂／多指标报告的预先多重性方案是否足够。 |  |
