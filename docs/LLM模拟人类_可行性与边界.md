# 用 LLM 模拟人类：可行性、边界与混合设计（工作文档）

日期：2026-09-25 · 状态：讨论稿 v0.2（2026-09-26 更新） · 关联：`docs/AI智能体实验设计.md`、`docs/典型画像_参数标定.md`、`docs/数据源与公开数据库清单.md`、论文 v1.0 §14–§15

> **2026-09-26 战略转向注记**：团队决定采取**零招募**方针——实验主对象为 AI 智能体队列（论文 §15 三层架构、`docs/AI智能体实验设计.md`），人类数据只用可在线低成本获取的公开资源作转移锚点。本文档 §4 的"最小人类样本方案"（20–30 人）**降级为未来可招募时的备选预案，不再是默认路径**：其中线人访谈与便利样本行为实验取消，功能由数字痕迹法与在线人类数据锚点（论文 §15.3）承接；"不可替代表"中的人类环节全部推迟至 L3（推迟的 RCT）。其余分析（可替代性矩阵、理论边界论证、LLM 偏差谱系与验证电池）不变且被新方案全部继承。

**背景**：团队无法按职业配额招募足量被试。本文档回答：哪些环节可以用 LLM 模拟人类替代、哪些不能、为什么（用论文自身框架论证）、以及"最小人类样本 + LLM 代理"的混合设计。

---

## 0 直接回答

**能替代约 70% 的人类数据需求，但有三条不可替代的底线。**

可替代的核心逻辑：本框架需要的人类数据分两类——
- **信息处理与决策行为**（标注、判断、选择）：LLM 代理有成熟先例，配验证协议后合法；
- **生理—情感—纵向可塑性**（情绪劫持效应 $\delta_{\mathrm{human}}$、12 周德性演化 $\theta$、真实 RCT 因果效应）：LLM 没有唤起系统、没有跨会话可塑性、没有被试身份，**这三样是本体论缺失，不是工程缺口**。

三条底线：(1) $\delta_{\mathrm{human}}$ 用文献效应量做先验，不用 LLM 测；(2) RCT（阶段四）必须以真人落地，可推迟、可缩小、可先去分层；(3) 一切 LLM 仿真结论标注"条件于模拟保真度"，可证伪清单 P1–P12 不得仅凭 LLM 仿真宣称"通过"。

## 1 逐模块可替代性矩阵

| 环节 | 原计划人类需求 | LLM 可替代性 | 说明与边界 |
|---|---|---|---|
| $\rho_c$、$p_{\min}$ 语料统计 | 0 人 | **完全**（本就不需要人） | LLM 反而在此最能发力：命题归并 $\kappa$、信源分类、覆盖检测都是内容侧任务，不需要"像人" |
| 生产者代理（§14.1 三类生产者+对抗适应） | 0 人 | **完全** | LLM 生成诚实/煽情/操纵内容并演化逃逸策略；即红队。安全护栏+审查，不发布原始载荷 |
| 消费者主体群（§14.2） | 0 人（本就是抽象模型） | **双层架构** | 参数化主体 $10^4$（人口统计）+ LLM 主体 ~100–500（行为真实感）；**冲动项 $g^{(1)}$ 必须框架层参数化注入**，不能指望 LLM"演情绪"（见 §2） |
| $d'$ 标注（每画像 5–10 人×200 条） | 25–50 人 | **部分** | LLM 预标注 + 小规模人类金标审计（每画像 2–3 人×50 条）。LLM 标注测的是"主体间合理性"而非真 $g^{(2)}$——作先验分布用，不作真值用 |
| $\delta_{\mathrm{AI}}$（提示注入侧） | 0 人 | **完全** | 本来就是在模型上测（TensorTrust/HackAPrompt/BIPIA） |
| $\delta_{\mathrm{human}}$（情绪劫持） | 实验被试 | **不可替代** | 心理生理量；LLM 无唤起系统，且双向失真（见 §2）。用元分析效应量做先验（Chan 2017、Bail 2018 范式、Pennycook-Rand OSF） |
| $\theta$ 动力学（12 周升华） | RCT 被试 | **不可替代** | LLM 无真实纵向可塑性（微调/记忆≠德性形成）。仿真中按 §10.1 参数化模拟（本就如此设计），真人验证留给 RCT |
| RCT H1–H7 | 510 人 | **不可替代**（可推迟/缩小） | 因果主张必须落在真人上，否则论文可证伪性声明失效。缩减方案见 §4 |
| $g^{(2)}$ 声明/画像的决策集 | 每画像招募 | **间接替代** | 数字痕迹法：知乎职业话题、Reddit（r/residency、r/personalfinance、r/PhD）、小红书/豆瓣小组、公开 vlog → 提取决策集与 $E^*$ 样本（观察性数据，注意平台条款与匿名化）；能招到每画像 1 名"线人"做 1 小时访谈更好 |
| 紧急覆盖桌面演练 | 专家组 | **完全** | LLM 扮演场景+机器行动，团队扮演反思层 $R$ |
| 公共层认证/每周抽查 10 条 | 审计员 | **大部分** | LLM 辅助审计 + 团队复核（16.5 本就规定人工抽查，团队自己够） |

## 2 理论根据：为什么恰好是这些不能替代（用论文自己的框架）

这是本项目特有的优势——**框架的公理系统直接给出了 LLM 模拟的失效边界**：

1. **公理 3（$g^{(1)}/g^{(2)}$ 分离）在 LLM 身上被压缩**。LLM 没有内脏性冲动：不会饿、不会累、不会被高唤起内容"劫持注意力权重"。后果是系统性的、方向可预测的失真：**LLM 代理会低估情绪劫持效应（$\delta$）、低估冲动消费、高估合规与耐心**。讽刺的是它同时在另一个方向失真——对指令性内容过度服从（这正是提示注入面）。两个失真不同源、不同向，不能相互抵消，必须分别参数化：冲动项由框架层注入（概率性抬高唤起维度权重），服从性由红队实测。
2. **公理 1（有限性）对 LLM 是虚拟的**。LLM 代理不疲劳，$T$ 约束必须外部强制执行；机会成本行为（定理 8.1 的无套利调度）在 LLM 上会表现为"超人类理性"——这会使 S2 策略的仿真收益被高估。对策：框架层硬预算 + 有界理性提示 + 与参数化主体的结果对照。
3. **命题 10.2（去技能化不可能三角）自指地适用于研究方法论本身**：若用 LLM 代做"Brier 预测"再去测校准，测的是模型不是人——$\hat\theta$ 与 $\theta$ 脱钩，I5 失效。**这条命题就是"RCT 不可用 LLM 替代"的形式化证明**：升华主张（H1/P11）的观测端必须是真人的判断形成过程。
4. **公理 4（证词依赖）**：画像的价值在于其真实证词网络（医生信学会、投资者信披露平台、家长信本地群）。LLM 角色扮演给的是"关于该职业的百科式拟像"，数字痕迹给的才是该职业**实际的信息食谱**。前者用于生成假设，后者用于参数化。

## 3 文献证据：LLM 模拟人类目前能做什么（⚠ = 需核实最新版本）

**支持性证据**（方向可复现、量级有偏差是共识）：

- Argyle et al. (2023, *Political Analysis*)：LLM 可复现 ANES 调查 response 分布（"silicon sampling"）；persona 条件化后仍有残余偏差——**过度代表高学历、高收入、（美国语境下）自由派人群**；
- Aher et al. (2023)：LLM 重放经典心理学实验（Milgram、最终博弈等），多数效应方向一致、量级不稳；
- Horton (2023, NBER w31122)：LLM 在经济学范式（禀赋效应、随机偏好选择）上部分复现人类行为，"homo silicus"概念；
- Dillion et al. (2023, *TiCS*)：心理量表对比——部分特质可模拟，依赖具身经验的特质失真；
- Park et al. (2023, UIST)：Generative Agents，25 主体社区涌现协调行为；
- Zhang et al. (2024, SIGIR, Agent4Rec) ⚠：1000 个 LLM 代理模拟推荐系统用户——与本项目 S1（参与优化基线）仿真直接同构，架构可借鉴；
- Zheng et al. (2023, NeurIPS)：LLM-as-judge 与人类评审一致性约 80%+（与人人一致性同量级）——支持预标注用法；
- Gao et al. (2023) 综述：LLM 社会代理的进展与挑战（同质化、评测缺失）。

**公认的系统性偏差**（对本项目的含义）：

| 偏差 | 对仿真的影响 | 对策 |
|---|---|---|
| 人口学偏差（高学历代理） | **P5（公民家长）是保真度最低的画像**——恰是工具保护价值最大的人群；P1–P4（职业话语在训练数据中丰富）保真度较高 | P5 结论最保守处理；数字痕迹锚定；RCT 阶段 P5 层必须真人 |
| 过度合规/过度理性 | 低估 $g^{(1)}$ 冲动、高估 S2 收益、高估 $q_t$ | 框架层冲动注入 + 时间压力 + 有界理性提示；与参数化主体对照 |
| 同质化（mode collapse） | 主体间行为相关被低估 → $k_{\mathrm{eff}}$ 类分析失真 | 多基座模型混用、采样温度、persona 差异化、成对相关度检查 |
| persona 漂移 | 长仿真中画像退化 | 定期一致性测试（人口学问卷重测）+ 重置机制 |
| 对情绪诉求的响应模式与人类不同 | $\delta$、反噬效应不可信 | 见 §2.1：这两项不由 LLM 产出 |

**方法学争论（2024–2025）⚠**：复现研究显示效应方向多数稳定但量级差异大；"LLM 数据能否作为人类数据的前置证据"尚无定论。本项目立场：**LLM 仿真 = 理论内部一致性与机制检验的工具，不是效应量的证据来源**——这与论文 §14 对仿真的定位（"产出默认先验表 + 检验可证伪命题"）一致，且 P11（升华）明确留给 RCT。

## 4 最小人类样本方案（**已降级为备选预案**——2026-09-26 起默认路径为 `docs/AI智能体实验设计.md` 的零招募三层架构；以下内容仅在未来可招募时启用）

1. **团队成员（n≈5–10）**：$d'$ 金标审计的通用条目、协议试跑、公共层每周抽查、桌面演练的反思层角色；
2. **便利样本（学生/朋友，n≈10–15）**：行为学校验实验——重放 3 个已发表范式（准确性提示、情绪唤起下的判断偏移、 misinformation 辨别 $d'$），为 LLM 代理提供**真人锚点**（这是验证电池的对照数据，不是画像数据）；
3. **每画像 1 名"线人"（n≈5，付费 1 小时访谈）**：半结构访谈提取决策集、监测清单、信息日常与失败案例。渠道：熟人网络、在行/专家咨询平台、职业社群版主。招不齐时的降级方案：数字痕迹 + 该职业的公开自述材料（书、播客、知乎高赞职业回答）；
4. **RCT 的缩减与推迟**（阶段四重设计）：
   - **先行试点**：单臂 + 历史对照（n≈30，团队+便利样本），目标是验证工具链、留存率、测量仪器灵敏度——不是效应检验；
   - **分层推迟**：首个正式 RCT 不做画像分层（合并检验 H1/H2，样本量按 §15.2 的 510 不变），画像调节效应（H4–H7 的分层版本）留待多中心二期；
   - **外部合作**：医学院临床研究中心（有被试池与 IRB 通道）、商学院案例中心（企业主被试）、中学家长委员会（P5）——用工具授权换被试渠道，符合 §15.5"实验后向对照组开放工具"的精神；
5. **数字痕迹采集规范**：仅公开内容、去标识化、聚合报告、遵守平台条款；用途限于画像参数化与 $E^*$ 样本构建。

## 5 LLM 代理的实施规范（阶段三工程）

**双层架构**（已写入论文 §14.2）：
- **参数化主体层**（$10^4$，按论文 §14.2 原设计）：便宜、可复现、方差可控，承担全部人口级 KPI；
- **LLM 主体层**（100–500 个）：行为真实感与机制检验，承担案例研究、边界探测、交付层文案的可用性感受。

**LLM 主体协议**：
- persona 卡 = 画像文档 §1 表格 + 数字痕迹摘要 + 声明的决策集 $D$ 与 $g^{(2)}$ 概要；
- **框架层强制**（不依赖模型自觉）：预算 $T$ 硬约束、冲动项注入（每期以画像相关概率临时抬高唤起维度权重——$g^{(1)}$ 的外生实现）、冷却队列延迟；
- 事件驱动调用：仅在关键决策/操控暴露/阈值穿越时调用 LLM，常规消费走参数化路径（成本控制）；
- 多基座混用（≥2 个模型家族）防单模型偏差。

**验证电池（任何 LLM 仿真结果发表前必过）**：
1. **真人范式重放**：用 LLM 代理重放 3 个已发表人类实验（Bail 2018 反噬范式、Pennycook-Rand 准确性提示、辨别力 $d'$ 测验），报告与人类效应量的方向一致性与量级偏差——偏差进入仿真的不确定性预算；
2. **persona 一致性**：跨会话人口学/态度问卷重测相关；
3. **同质化检查**：主体间行为相关矩阵 vs 参数化主体的先验异质性；
4. **锚点对齐**：与 §4.2 便利样本的真人数据在重叠任务上对齐。

**报告规范**：全部 LLM 仿真结论标注"条件于模拟保真度（验证电池 v 版本）"；P1–P12 中 **P11（升华/反噬）不得以 LLM 仿真作为通过依据**；P10（生态相变）等机制类命题可接受仿真证据但注明代理类型。

## 6 伦理与研究诚信

- 仿真数据**永不冒充人类数据**：数据集、日志、论文表格三处标注生成方式；
- LLM 生成操纵内容（红队）：安全护栏、机构审查、只发布检测器与统计，不发布原始载荷；
- 数字痕迹：隐私、去标识化、平台条款；
- LLM 仿真本身不需 IRB，但发表须声明模拟属性；真人环节（§4 的 2/3/4 项）仍走伦理审查。
