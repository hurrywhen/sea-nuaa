# 典型画像与地基参数标定（工作文档）

日期：2026-09-25 · 状态：讨论稿 v0.1 · 关联：论文 v1.0 §13–§15，撰写说明 §5

**目的**：论文 v1.0 的四个地基参数（$p_{\min}$、$\rho_c$、$d'$、$\delta$）都随"人 × 领域"变化。本文档回答三个问题：(1) 每个参数到底由谁决定、个体间差异有多大；(2) 用五个典型画像给出参数的具体形态与标定先验；(3) 画像如何进入仿真与 AI 智能体队列实验（阶段三）、在线人类数据锚点（阶段四）与部署（阶段五）。**2026-09-26 零招募方针下，画像主要以"智能体 persona 卡"形式实例化**（数字痕迹生成，规范见 `docs/AI智能体实验设计.md` §2.2）；人类被试环节全部推迟至论文 §15.5（L3）。

## 0 参数的变异结构：谁随人变、谁随领域变

| 参数 | 含义（定理出处） | 主要决定因素 | 个体间差异 | 领域间差异 | 标定方法 |
|---|---|---|---|---|---|
| $\rho_c$ | 命题坍缩比（定义 4.3、推论 6.1） | **信息生态**（领域属性为主） | 小（同一平台内基本一致） | **大**（突发新闻 10–30；学术前沿 1–3） | 语料直接统计：文档数/命题数（成本最低，优先做） |
| $p_{\min}$ | 可信类覆盖下界（假设 R1、定理 7.1） | **人 × 领域**（监测清单质量 × 领域信源冗余度） | 中（取决于清单选择） | 大（医疗/财经高，学术/长尾低） | 历史语料回测：已知关键命题被各信源类覆盖的频率 |
| $d'$ | 评分分离度（定理 6.1） | **人 × 评分器**（$g^{(2)}$/决策集声明清晰度 × 领域可分性） | **大** | 中 | 标注实验：本人标注关键/非关键 200 条，测评分器 ROC 分离度（同时校准声明质量） |
| $\delta$ | 单条操控影响（假设 F1、定理 9.1–9.2） | **人**（特质易感性 × 专业训练）+ 内容生态 | **大** | 中 | 行为实验：单条高唤起内容暴露前后判断偏移；AI 实例按注入载荷编辑距离标定 |
| $T$、$\lvert E^*\rvert$ | 预算与关键规模（命题 6.3） | 人 | 大 | 中 | 自我报告 + 设备时间日志校验 |

**结论**：是的，四个参数"因人而异"，但**变异的轴不同**——$\rho_c$ 主要是领域的函数（同领域的人共享），$p_{\min}$ 是人与领域的联合函数，$d'$ 和 $\delta$ 个体差异最大。这正是论文采取三层参数结构的理由：

```
定理（函数关系，普适） → 默认先验表（人群级，阶段三仿真产出）
                       → 画像先验（本文档，5 个典型包）
                       → 个体标定（阶段五部署，渐进修订）
```

定理不需要知道参数值——它给出"参数取某值时保证是什么"；画像与标定负责把现实的人放进参数空间。

## 1 五个典型画像

### P1 临床医生（三甲主治，内科）

| 维度 | 内容 |
|---|---|
| 认知预算 $T$ | ≈30 分钟/日（查房间隙碎片化） |
| 决策集 $D$ | 治疗方案调整；用药/换药；院感应对；转诊；患者教育 |
| 关键命题类型 | 临床指南更新；药物安全警示（NMPA/FDA）；新发传染病监测；本专业高影响新证据 |
| 监测清单示例 | 卫健委/疾控通报；药监安全警示；专科学会指南通道；顶刊"最新研究"栏；专业核心期刊目次 |
| 参数画像 | $p_{\min}$ **高**（0.8–0.95：医疗信源冗余极强，指南必多源）；$\rho_c$ 中高（8–15：新闻级事件高转载，专业证据以一手文献为主）；$d'$ 中高（决策集清晰，但术语噪声重）；$\delta$ 低–中（专业训练即"接种"，但疲劳抬高冲动性）；$\lvert E^*\rvert$ ≈ 3–5/日 |
| 最吃重的定理 | 定理 7.1（冗余覆盖是主通道）；第 11 章紧急覆盖（药物召回、传染病报告时限）；防火墙（患者转述的健康谣言进入决策链） |
| 压力场景 | 单源专业预印本（低冗余 ⇒ 监控清单兜底）；时效警示（冷却队列 vs 直通的时延代价） |
| 默认包要点 | 安全警示类误报阈 $\tau_m$ 最宽松（漏报代价极高）；耐久尺度 $\lambda_d$ 偏向时效加权 |

### P2 投资者（个人/半专业）

| 维度 | 内容 |
|---|---|
| $T$ | ≈60 分钟/日（盘前盘后集中） |
| $D$ | 持仓增减；止损；对冲；事件驱动交易；欺诈标的回避 |
| 关键命题类型 | 财报与业绩预告；央行与监管政策；行业供需数据；黑天鹅（地缘/灾害/金融风险） |
| 监测清单示例 | 交易所指定披露平台（一手！）；通讯社财经频道；央行/监管机构公告栏；持仓公司公告；少数经验证的研究信源 |
| 参数画像 | $p_{\min}$ **制度性来源**（实测：监管一手类 p̂_min=1.00 legal/0.70 market——8-K 四日规则；通讯社 0.25/财经 0.15/科技媒体 0.04 market——多类冗余可用）；$\rho_c$ **实测 8.19**（EDGAR+10 域新闻层，落入论文区间 [5,20]）；$d'$ **双真值分裂**（实测：法定关键 **3.49** / 市场关键 0.54——市场维度仅弱可预测，主要由结构承载）；$\delta$ **高**（FOMO 与恐慌是最强劫持通道，操纵者定向攻击）；$\lvert E^*\rvert$ ≈ 5–15/日（随行情波动）；H4 强形式：组合内召回 0.910@m=5（配额超额下逼近 0.95 线） |
| 最吃重的定理 | **定理 6.1**（极端过滤+时效性使分离度矛盾最尖锐 ⇒ 一手信源直通是命脉）；定理 9.1–9.2（坐庄谣言、AI 伪造"内幕"）；第 11 章（黑天鹅止损预授权）；命题 6.2（错过一次黑天鹅的代价 > 全部日常条目之和——Pareto 泄漏的极端形态）。**试点实测（2026-09-27，EDGAR+CDX 新闻层）**：法定重大性深植元数据（d′_legal=2.65）、市场重大性仅部分可由注意力信号预测（d′_market=0.60）；组合直通 m=5 时组合内召回 0.952（H4 达成）；91% 移动日不可归因 ⇒ 新闻层全量化+公共层是刚需 |
| 压力场景 | 协同拉抬（多账号伪独立 ⇒ $k_{\mathrm{eff}}$ 崩塌）；突发行情（预算冲击，命题 6.3 报警） |
| 默认包要点 | $n_{\max}$ 最严格；未经一手信源确认的传闻强制降权；$D_{\mathrm{adv}}$ 只允许"减风险"类行动（**永不自动买入**——可逆性偏序在金融域的实例） |

### P3 前沿研究者（AI 方向博士生 / PI）

| 维度 | 内容 |
|---|---|
| $T$ | ≈90 分钟/日阅读 + 周末深度时段（弹性大） |
| $D$ | 选题与转向；实验设计；论文写作与投稿；合作与招聘；工具/数据集采用 |
| 关键命题类型 | 前沿论文（**常为 arXiv 单源，无冗余！**）；竞争实验室动态；数据集/开源工具发布；审稿与社区风向；资助征集 |
| 监测清单示例 | arXiv 特定类目日馈 + 关键作者清单（领域内竞争者与合作者 top 50）；GitHub org/repo releases；顶会 accept 列表；少数高质量 newsletter |
| 参数画像 | $p_{\min}$ **低**（试点实测：作者粒度清单 0.02、机构粒度 0.17–0.37——R1 假设对此画像最弱！且 $\hat p_{\min}$ 是清单构建设计变量，见 `sim/pilot/results/PILOT_REPORT.md`）；$\rho_c$ **低**（实测 1.0：学术命题没有十家转载）；$d'$ **实测低**（元数据+TF-IDF 0.77、语义嵌入 0.73——两特征族收敛：关键性在投稿时点内在不可预测；但 LLM 判断层在 digest 内排序上胜过 ρ=0.4 proxy，见 llm_replay_STATUS）；$\delta$ 低（操纵性内容少，但"焦虑营销/同行压力贩卖"存在）；$\lvert E^*\rvert$ ≈ 5–20/周 |
| 最吃重的定理 | **命题 7.2 监控清单直通是命脉**——论文 §7.4 承认的"R1 弱点"正是此画像的日常；命题 8.1 Pandora 探索（持续发现新作者/新方向，探索预算占比五画像最高）；定理 8.2 EIG 查询（文献检索是 pull 主战场）；定理 7.4 第二因子（通道 II 发现权重最高） |
| 压力场景 | 低冗余长尾（§14.5(c) 即为此设计）；选题漂移（$g^{(2)}$ 本身演化 ⇒ 决策集修订通道） |
| 默认包要点 | $T_{\mathrm{pull}}$ 占比最高（≥40%）；监控清单容量最大；新颖度权重高；公共层 $\gamma$ 低（学科共同体的"共享现实"由会议/期刊承担，不经大众媒介） |

## 2 画像如何进入三个阶段

### 2.1 阶段三仿真（论文 §14.2 升级点）

- $10^4$ 主体按五画像**分层参数化**（建议占比 P1:P2:P3:P4:P5 = 15:20:20:15:30，接近工具早期用户的现实结构；正式仿真前用目标用户调研修正）；
- 每层参数从画像先验区间采样（本文档 §1 表格即采样域），层内再异质化；
- **KPI 按画像分层报告**：同一预言在不同画像上强度不同（冗余覆盖对 P1/P2 强、对 P3 弱且必须由清单补偿；无套利调度增益对 P4 最大）——分层报告把 §13 的可证伪清单 P1–P12 升级为**画像 × 命题矩阵**，是更强、更精细的证伪检验；任何一格系统性失败都定位到具体假设（如 P3 格的召回失败指向 R1 而非评分器）。

### 2.2 阶段三前置：标定实验（按成本排序）

（各参数可用的公开数据库、申请渠道与自建缺口，详见配套文档 `docs/数据源与公开数据库清单.md`。）

1. **$\rho_c$、$p_{\min}$**（最便宜，公开语料直接测量）：每画像构建 2–4 周语料快照，直接统计。P3 需要 arXiv+GitHub 快照；P5 需要本地信源快照；
2. **$d'$**（中等，零招募版）：团队自标金标（每画像 50 条：先写决策集声明，再标注"关键/边缘/噪声"）+ LLM 预标注 + **语料真值清单替代**（FDA/NMPA 警示、EDGAR/巨潮披露事件、高被引论文——见数据清单文档 §1.2），测评分器分离度；金标同时校准"$g^{(2)}$ 声明质量"这个此前无法测量的量；
3. **$\delta$**（零招募版）：$\delta_{\mathrm{human}}$ 不再做新实验——用已发表元分析效应量做先验（Chan et al. 2017；Bail 2018 Dataverse 复现数据；Pennycook-Rand OSF），精确值推迟至 L3；$\delta_{\mathrm{AI}}$ 直接在模型上测（TensorTrust/HackAPrompt/BIPIA 载荷家族的注入成功率与编辑距离）。

### 2.3 阶段四验证（论文 §15 三层架构下的角色）

- 画像作为**因子**进入 AI 智能体队列实验（论文 §15.2）：处理臂 × 画像 × 环境 × 对抗强度的主效应设计，H1'–H7' 全部做画像调节分析（预期与人类版一致：H4' 召回对 P3 须验证"清单补偿"；H2' 效率对 P4 增益最大；H7' 去技能化的 AI 类比对 P5 最关键）；
- 在线人类数据锚点（论文 §15.3）按画像匹配：P2 ↔ First Call/EDGAR、P1 ↔ FDA 警示、P3 ↔ Semantic Scholar、P5 ↔ 辟谣存档与热榜；
- 原"分层随机 RCT + 每层 60–70 人"的设计**保留为 L3 future protocol**（论文 §15.5），启动条件见该节。

### 2.4 阶段五部署

- 五套**默认参数包**（监控清单模板 + 阈值先验 + 预算划分先验）；
- Onboarding：选最近画像 → 立即获得可用系统 → 个体渐进修订（每周校准会驱动）；
- §16.2"默认值即价值观"的落地：每个默认参数标注**画像来源与仿真依据**，用户可见"这个阈值为什么是 0.7：因为在你的画像的仿真中它使漏报率 ≤2% 且误报成本可接受"。

## 3 开放问题

1. **画像覆盖度**：五个画像不覆盖所有人（政府职员、记者、工程师、退休者、学生……）。立场：画像是**先验结构而非分类学**——部署允许"画像基底 + 个体微调"的自由组合；仿真中可增加第六层"混合/未声明"检验兜底逻辑；
2. **画像漂移**：个体决策集随人生阶段演化（P5 家长 → 慢病管理近似 P1 视角）。季度目标修订会（C 类）兼作画像重估时点；
3. **跨画像公平**：$d'$ 标定依赖声明质量，高教育画像系统性占优——需要"模糊声明兜底"设计（P5 的公共层与清单模板权重上调即是），并把"声明质量改善"本身纳入升华课程（§10）的目标；
4. **画像的先验来源**：本文档的参数区间是**基于领域常识的工作假设**，全部标注为待标定——阶段三前置实验（§2.2）的第一版输出就是把这些区间换成实测值。
