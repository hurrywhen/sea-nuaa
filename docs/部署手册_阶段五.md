## 2 g² 声明实例化（个人参数填入）

1. 复制模板：`cp sim/sea_deploy/personas/researcher.example.json sim/sea_deploy/personas/<你的名字>.json`
2. 填写（这就是论文 §4.5 的 g² 声明行为）：
   - `g2_decision_set`：你的**活跃决策**（每项：决策名、视界天数、关键词）——关键性以此定义（定义 4.6），不是"兴趣"而是"要做的决定"；
   - `watchlist.authors`：追踪的具体人（合作者/竞争者；可空——arXiv 机构字段不可靠，机构粒度清单留给月度 A7 重建）；
   - `budget_per_day`：每日深读名额（研究者画像默认 3）；
   - `whitelist_urgent`：A9 防火墙的预先授权白名单（定理 11.1 Ulysses 契约——**只能 S2 签字修订**）；
   - `channels` / `certification`：**域配置不要乱动**——学术单源域 `allocator=fixed`、`certification.enabled=false` 来自 P3 移植验证的域条件性结论（金融多类域才开 adaptive + A8）。
3. **S2 签字 = git commit**（提交记录即签字与冷却期起点；修订历史即 S4 审计链）。

## 3 每日运行

```bash
cd sim
python3 -m sea_deploy.daily_run --llm                      # 今日简报（LLM 判断层）
python3 -m sea_deploy.daily_run --llm --persona sea_deploy/personas/<你>.json
python3 -m sea_deploy.daily_run                            # 纯参数化（无 LLM，离线兜底）
python3 -m sea_deploy.telemetry_report                     # 遥测周报
```

可选 cron（团队自定，opt-in）：`30 7 * * * cd ~/sea/sim && python3 -m sea_deploy.daily_run --llm >> sea_deploy/out/cron.log 2>&1`

**产物**：`sea_deploy/out/digest_YYYY-MM-DD.md`（原子落盘）+ `telemetry.jsonl`（追加+fsync）。
**失败语义**：抓取失败→不写遥测（不污染纵向记录）；LLM 失败→自动回退参数化排序并如实记 `llm_used=false`（管线永不断）。

## 5 已知边界（诚实声明）

1. **v0 评分器 = 关键词重叠启发式**——2026 实时论文无地面真值（引用年延迟，P3 移植验证的核心域差异）；首跑已见其语义盲区（LLM 把校准论文关联到"实验设计"，关键词只给"工具/数据集"0.29 分）。遥测累积 ≥90 天后用事后标注训练真评分器（A10 部署形态）；
2. **A8 认证关闭**（单类域退化）、**A5 固定配额**（低波动域自适应为净成本）——均为 P3 移植验证结论的部署兑现，换域（金融多类）时按域开关；
3. **A9 防火墙空转**（arXiv 无平台 salience 信号；隔离恒 0）——接入社媒/推送流时自动生效（机制已验证：impulse_p=0.45 档召回 0.341→0.581）；
4. θ_cal 人类侧测量不可由机器代做（命题 10.2）——本工具的遥测是**团队自用侧**锚点，与 AI 队列（L1）对照构成转移桥，不替代人类校准。
