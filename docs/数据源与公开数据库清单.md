# 数据源与公开数据库清单：四地基参数 × 五画像（工作文档）

日期：2026-09-25 · 状态：讨论稿 v0.1 · 关联：`docs/典型画像_参数标定.md`、论文 v1.0 §13–§15

> 说明：本清单基于撰写时的领域知识整理；各数据源的**当前可获取性、许可条款与版本**在启动标定前须逐一核实（标注 ⚠ 者尤其）。商业库先盘点高校/机构既有订阅。

---

## 0 总原则：四个参数对应三种数据形态

| 数据形态 | 成本 | 适用参数 | 结论 |
|---|---|---|---|
| **A. 公开语料直接测量** | ≈0（下载+统计） | $\rho_c$、$p_{\min}$（新闻/财经/学术域） | 有成熟公开库，**第一批就做** |
| **B. 申请制/商业库 + 公开真值清单** | 低—中 | $d'$ 的方法学验证；部分 $p_{\min}$ | 公开数据只能做**方法学代理**；画像专属 $d'$ 必须自采标注 |
| **C. 团队自标 + 文献效应量（零招募）** | 低—中 | $\delta$（文献先验）；$d'$ 金标；P4/P5 的 $p_{\min}$（本地域/竞对域自建采集） | 2026-09-26 起零招募：人类暴露实验取消，$\delta_{\mathrm{human}}$ 用元分析先验、精确值推迟至 L3 |

**核心判断**：结构性参数（$\rho_c, p_{\min}$）公开数据充足；$d'$ 的关键缺口是"决策关键性"真值——公开数据几乎只提供**点击**（一阶偏好 $g^{(1)}$），而框架需要的是**第二序重要性**（$g^{(2)}$ 关联），这个缺口必须自建（同时也是论文的贡献机会，见 §5）；$\delta$ 依赖已发表实验的效应量元分析 + 小样本补充。

## 1 按参数组织的数据源清单

### 1.1 $\rho_c$（命题坍缩比）与 $p_{\min}$（信源类覆盖下界）——形态 A 为主

| 数据源 | 内容 | 获取 | 用途 |
|---|---|---|---|
| **GDELT 2.0** | 全球新闻事件库：每事件 `numMentions`（报道数）、每篇报道的源域名/语言/国家 | 免费（API + BigQuery 公开表） | **最重要的单一资源**：$\rho_c$ 直接 = numMentions 分布；按源域名分组 → 信源类划分与 $p_{\min}$ 回测；$k_{\mathrm{eff}}$ 方法学（所有权/地域/类型分组）可在其上验证 |
| **News2016zh / CLUE news2016** ⚠ | 250 万中文新闻，3189 个站点，**带源站点标签** | 免费（CLUE 官网） | 中文 $\rho_c$、源类划分、转载网络测量 |
| **THUCNews** | 74 万中文新闻（新浪 2005–2014，14 类） | 免费（清华开放） | 中文历史基线（注意年代偏旧，仅作方法学） |
| **SogouCS / SogouT 2012** ⚠ | 大规模中文新闻，带媒体来源标注 | 学术申请 | 中文转载冗余的年代对照 |
| **Common Crawl News（CC-News）/ C4 / RefinedWeb** | 网页级新闻抓取；其去重研究直接报告了网页新闻重复率 | 免费 | web 规模冗余先验；去重算法文献（近似串匹配）即命题归并 $\kappa$ 的工程参考 |
| **Signal-1M（Signal Media）** ⚠ | 100 万英文新闻，含跨媒体聚类 | 免费（研究许可） | 英文 $\rho_c$、聚类质量基线 |
| **Weibo21 / Weibo20**（微博谣言检测基准） | 谣言/真实事件传播树，带源与验证标签 | GitHub 公开 | 中文社交域 $\rho_c$；**谣言 vs 真实事件的冗余结构差异**（协同造假破坏 $k_{\mathrm{eff}}$ 的实证样本） |
| **PHEME** | 4 起突发事件的推特谣言传播+核实标注 | figshare 公开 | 突发事件早期"单一信源高关键性"样本（P3/P5 压力场景的现实对照） |
| **BuzzFeed Web-of-Lies**（Mimis & Corso） | 2 千余条假新闻+传播数据+用户 reactions | GitHub 公开 | 假新闻冗余结构；reactions（angry/scare）= 唤起度代理 |
| **tophub.today 类热榜聚合** ⚠ | 50+ 中文平台热榜的第三方存档 | 网页/需自建采集 | 重大公共事件的**跨平台冗余**实测（公共议程层 $k_c$ 认证参数的现实对照） |
| **ProMED-mail / WHO DON** | 传染病爆发报告（多源聚合，含报告链） | 免费订阅 | P1 的 $p_{\min}$ 直接测量（同一疫情事件被几类信源报告）；本身就是"冗余监测网"的活体样本 |
| **archive.org CDX 前缀查询**（✅ 已验证，2026-09-27） | 按 URL 前缀检索存档新闻（Reuters 按公司 slug、CNBC/Fortune 按月路径），返回 URL+存档时间戳 | 免费，无需换网络出口（`fetch_news.py`） | P2 新闻层的主通道：公司×日×域名 → 新闻量、信源类、ρ_c；注意 Reuters 发表日以存档日近似（±数日） |
| **Wikimedia Pageviews API**（✅ 已验证） | 公司维基页日浏览量（2019 全史可查） | 免费 REST，1 req/公司 | S1 参与度基线的真实注意力协变量；显著性事件的独立佐证 |
| **GDELT 原始事件文件**（✅ data.gdeltproject.org 可达；DOC API 仍限流） | 15 分钟粒度事件流（含 SOURCEURL） | 免费静态文件 | 市场级新闻环境强度协变量；注意是 15 分钟分片（全月 2880 片，建议抽样） |

**方法**：取画像对应领域的 2–4 周快照 → 用命题归并（嵌入聚类 + 规则，参考 CC 去重文献）构建 $E$ 与 $D_e$ → 统计 $\hat\rho_c$；对"关键命题"子集（由 1.2 的真值清单定义）统计各信源类覆盖频率 → $\hat p_{\min}$ 与覆盖相关矩阵 → $\hat k_{\mathrm{eff}}$。

### 1.2 $d'$（评分分离度）——形态 B：公开真值代理 + 自采标注

$d'$ 需要"对该画像决策关键/不关键"的地面真值。公开数据里没有现成的，但有**领域代理真值**可先验证方法学：

| 数据源 | 真值含义 | 获取 | 对应画像 |
|---|---|---|---|
| **FDA Safety Communications / MedWatch**；**NMPA 药品警示公告** | "医疗关键事件"官方清单（免费、带日期） | 公开 | P1：用媒体语料回测"官方警示发布前后各类信源是否覆盖"→ $p_{\min}$；评分器对警示类内容的分离度 → $d'$ 方法学 |
| **SEC EDGAR**（美）/ **巨潮资讯 cninfo**（A 股指定披露） | 法定披露事件 = 投资决策关键命题的官方真值 | 免费（EDGAR 有 API；巨潮可检索/爬取） | P2：披露事件 vs 全量财经流的分离度标定 |
| **First Call / Ding et al. (2015)** ⚠ | S&P500 公司新闻 + 市场反应标注（market-moving news = "决策关键"的行为学真值） | 学术申请 | P2 的 $d'$ 最强公开代理 |
| **RavenPack News Analytics**（商业） | 每条新闻的事件相关度/新颖度/情感打分——**商业化的 $d'$ 操作** | 商业（高校或有订阅） | 方法学参照：我们的评分器与它的分歧即 $g^{(2)}$ 个性化的价值所在 |
| **Semantic Scholar / OpenAlex**（免费 API）+ **Altmetric**（商业） | 论文引用数 = 事后重要性；Altmetric 媒体关注度 = 学术事件的公众冗余 | 免费/商业 | P3：高被引论文发布当时的媒体/社交覆盖 → 学术域 $p_{\min}$（预期证实"低冗余"假设）；arXiv API 免费（含版本史） |
| **EurekAlert**（科学新闻稿库） | 研究→科普媒体的 pickup 链 | 公开浏览 | P3 域 $\rho_c$（学术命题进入大众层的坍缩比） |
| **MIND / xMIND**（微软新闻数据集）⚠ | 100 万+用户、16 万新闻、点击日志 | 免费（研究许可申请） | **人群级方法学**：评分器特征工程、仿真主体初始化。**根本局限：点击是 $g^{(1)}$ 不是 $g^{(2)}$**——只能做代理，不能当真值（这正是公理 3 的区分） |
| **TREC News Track** 相关性判定 | 主题级相关性标注范式 | 免费（NIST） | 标注实验设计的方法学模板 |

**金标标注（零招募版）**：团队自标每画像 50 条（先写决策集声明 $D$，再对样本流标注"关键/边缘/噪声"）+ LLM 预标注（经金标审计一致性后使用）+ 语料真值清单替代大部分需求（上表），测评分器 ROC → 画像 $d'$ 先验。此标注集**自建后可公开发布**（见 §5 空白点）。

### 1.3 $\delta$（单条操控影响）——形态 C：已发表效应量 + 小样本实验

| 数据源 | 内容 | 获取 | 用途 |
|---|---|---|---|
| **Bail et al. (2018) 复现数据** | 对立观点暴露→情感极化的实验数据与量表 | Harvard Dataverse 公开 | 反噬监测（§15.3）与 $\delta$ 的情绪通路先验；实验范式直接借用 |
| **Chan et al. (2017)、Ecker et al. (2022) 等元分析** | 纠正/持续影响效应量 | 论文附表公开 | $\delta$ 的文献先验（单条误导性内容的信念偏移效应量分布） |
| **Vosoughi et al. (2018) 数据** ⚠ | 真假新闻传播级联（Twitter） | 申请 | 情绪唤起与扩散速度关系 → $\delta$ 的内容特征映射 |
| **Pennycook & Rand OSF 仓库** | 准确性提示系列实验（部分数据公开） | OSF | 提示干预效应量 → 防火墙"冷静化重述"的参数 |
| **Roozenbeek & van der Linden（Bad News）** | 接种游戏前后辨别力数据（部分公开） | OSF/联系作者 | P5 画像的接种式交付注解的效应量 |
| **SemEval-2020 Task 11 宣传技术语料（PTC）** | 新闻文章 × 18 种宣传技术标注 | 公开（任务官网） | **$\rho_m$ 检测器训练集**；按技术类型分组标定 $\delta$（诉诸恐惧 vs 稻草人 vs 洗白……） |
| **Persuasion 数据集（Wei et al., 2023）** | 广告中的说服技术标注（政治+商业） | GitHub 公开 | 同上，商业操纵维度 |
| **ANES**（美国选举研究）/ **GSS** | 情感极化、媒体信任的长期调查 | 免费下载 | 反噬量表与 $\theta$ 测量的现成工具；跨人群基线 |
| **AI 实例**：TensorTrust、HackAPrompt（HuggingFace）、BIPIA、InjecAgent、HarmBench ⚠ | 众包提示注入攻防对（TensorTrust 10 万+ 攻防样本） | 多为公开 | $\delta_{\mathrm{AI}}$ 直接标定：按载荷家族统计攻击成功率与有效编辑距离 → F1 假设的机器侧实证 |
| **Deepfake Detection Challenge / FaceForensics++** | 深伪检测数据 | 公开 | 深度伪造类载荷的 $\rho_m$ 检测器 |

**方法**：$\delta_{\mathrm{human}}$ 先验 = 元分析效应量换算（信念偏移 × 决策敏感度；Chan et al. 2017、Bail 2018 Dataverse、Pennycook-Rand OSF），精确值推迟至 L3（不做新的人类暴露实验）；$\delta_{\mathrm{AI}}$ = TensorTrust/HackAPrompt/BIPIA 载荷家族在目标模型上的注入成功率 × 有效编辑距离，直接实测。

## 4 关键注意事项（坑清单）

1. **点击 ≠ 重要**：几乎所有大规模公开数据（MIND、推荐系统日志、热搜）记录的都是 $g^{(1)}$（一阶冲动）。用它们标定 $d'$ 会系统性高估"参与度相关"特征——这正是公理 3 的区分在数据层的体现。公开数据做特征工程与人群仿真，真值必须来自"声明决策集后的标注"。
2. **英语/全国级偏向**：公开库覆盖英文与全国级议题好，中文本地域（P5）、垂直行业（P4）几乎空白——好在画像文档已预判这两类数据量最小（3–5 家竞对 × 8 周；1 个城区 × 4 周），自采可行。
3. **许可与合规**：GDELT/CC/政府公告/辟谣平台存档研究友好；MIND/First Call/Signal-1M 需申请协议；商业库（Wind/RavenPack/CSMAR/Altmetric/企查查）先盘点机构订阅；微博/热榜数据爬取遵守平台条款，仅用于研究且不存个人身份信息。
4. **时间漂移**：$\rho_c$ 与 $p_{\min}$ 随媒体生态变化——AI 生成内容自 2023 起已显著改变冗余结构（合成转载泛滥会**虚增** $\hat\rho_c$、伪增"多源覆盖"从而污染 $\hat p_{\min}$ 与 $\hat k_{\mathrm{eff}}$）。对策：只用最近 6–12 个月数据；命题归并时加内容指纹去合成转载；把"AI 内容污染下的冗余测量"列为仿真压力测试项（§14.5 新增 (h)）。
5. **中文操控标注空白**：PTC/Persuasion 均为英文 → $\rho_m$ 检测器的中文训练集需要自建（约 2000 条 × 18 技术标签，众包+专家复核）。这是空白点也是贡献点（见 §5）。
6. **$\delta$ 的伦理红线**：暴露实验不得使用现行流传的真实有害谣言；只用已辟谣历史材料、事后完整告知、提供即时纠正（§15.5 已规定；零招募方针下人类 $\delta$ 实验推迟至 L3，此处保留为规程）。
7. **EDGAR submissions 深度限制**（试点实测）：data.sec.gov 的 submissions JSON `recent` 块仅含每公司最近 ~1000 件申报，高频申报公司的 2019 年记录不全（505 家缓存 → 当月仅 903 件，系统性低估）；正式实验改用 daily-index（`https://www.sec.gov/Archives/edgar/daily-index/`）按日全量抓取。
8. **GDELT DOC API 对数据中心 IP 硬限流**（试点实测）：即使遵守官方 1 req/5s 仍持续 429——新闻层抓取需换住宅/办公网络出口执行（`fetch_p2.py` 代码就绪，缓存兼容）；新闻层缺失的后果已在 P2 报告 §5 量化（ρ_c 低估、93% 移动日不可归因）。

## 5 空白点 = 论文的配套数据贡献机会
