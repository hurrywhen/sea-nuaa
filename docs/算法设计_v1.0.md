## 0 设计原则（阶段三证据塑造的五条）

1. **证据先行绑定**：每个参数的默认值绑定先验表 v0.1 的实测条目（标注状态：实测/机制验证/条件性/冻结）；冻结项（k_c 原始计数、B2 效应量）**不得进入任何自动决策路径**。
2. **零后见可部署**：一切统计量（类基率、实体近因、清单覆盖）均为 walk-forward——只用当日之前的数据估计；验证与部署走同一条代码路径。
3. **抗俘获设计**：认证、排序、配额三处均已知会被注意力经济俘获（认证反转 lift 0.63×；配额饱和下排序质量是瓶颈）——对应模块内建相对稀缺性折扣与边际递减。
4. **家族可移植**：LLM 判断层是插件；行为参数（冲动易感 29–45%、校准 Brier 0.17–0.28、有效率 86–100%）按家族查表（O6 转移系数库），框架层强制不依赖模型自律。
5. **全程可审计**：每次隔离、再入、白名单旁路、配额改派都写 S4 审计日志条目（主权公理 S1–S4）。

## 3 模块规范

### A1 命题图构建器（`sea_algo/prop_graph.py`）

**职责**：把文档流坍缩为命题图（定义 4.2 的 κ: X → E），维护信源类覆盖（定义 4.4）与事件级归并。
**接口**：
- `collapse(docs, key_fn, class_fn, crit_fn) -> props`：按命题键分组；每命题记录 `n_docs / classes / legal_critical / market_critical`；评论类文档挂为注解（有界修正项，不占完整预算份额）。
- `aggregate_events(props) -> events`：(entity, date) 事件级归并（认证与查询的粒度——阶段三教训：文档族级归并会破坏认证语义）。
**理论锚**：ρ_c 实测 1.0（学术单源）/ 8.19（金融 10 域）——坍缩把文档级过滤比难题转化为命题级选择问题（推论 6.1）。
**复杂度**：O(|X|)。**守卫**：命题键冲突（同键异义）写入 S4 异常日志。

### A2 双通道选择器（`sea_algo/selector.py`）

**职责**：在预算 m 下执行"通道 I 清单直通 + 通道 II 评分发现"的配额选择（定理 6.1 分工：召回由结构承担、精度由评分承担）。
**规则**：
1. 通道 I 名额 = ⌈quota·m⌉（quota=0.6，机制验证），内部按 A4 保留值排序；
2. 通道 II 名额 = m − m_I，按诚实特征评分（d′ 0.54–0.77 实测——**不得**用作召回保证，只作排序）；
3. 供给不足报警（配额饱和是常态：P2 组合直通供给 4.7/日 > 名额 3）——报警触发 A5 重分配而非静默浪费；
4. 全部选择写 S4 日志（含落选项的分数，供审计复盘）。
**失效模式**：清单内排序质量差 ⇒ 配额内召回损失（滚动实验证实的瓶颈转移）——由 A4/A10 缓解。

### A3 EIG 查询规划器（`sea_algo/planner.py`）

**职责**：主动获取（pull）的查询选择——定理 8.2：最优查询最大化单位成本的期望信息增益。
**候选查询** q=(实体 e, 信源类 c)；**EIG 估计**（零后见）：

```
EIG(q) = p̂(crit | c, e, t) · V − κ · cost(c)
p̂ = p̂_c(walk-forward 类基率, Laplace 向全局基率 0.107 收缩)
    × recency(e) = 1/(1 + 0.5·Δdays(e))          # 近因：新近活跃实体更可能再有关键事件
    × entity_mult(e) = clip(p̂_e/base, ≤3)         # 实体关键性乘子
cost(c) = 类均文档数（walk-forward）               # 注意力成本代理
```

**输出**：Top-k 查询（k 由 A5 分配的 m_Q 决定）；查询结果回流 A1（新文档 → 命题图）。
**守卫**：估计饥饿（某类长期未被查询 → 基率过期）由 A5 探索底线覆盖。

### A4 Pandora/Whittle 调度器（`sea_algo/scheduler.py`）

**职责**：通道 I 内部与深读名额的开箱序（命题 8.1：预算约束下的 Pandora 盒问题；§8.6：Whittle 指数在单名额退化下的 Gittins 序）。
**保留值**（Bernoulli 收益 V、开箱成本 c、影子价格 ν）：

```
z_i = V − c/p̂_i        （Weitzman 指数两点分布解）
准入：z_i ≥ ν  ⇔  p̂_i ≥ c/(V−ν)     # 指数策略退化为校准阈值——定理 8.1 无套利的可计算形式
```

p̂_i 按（命题 family × 首类）walk-forward 估计（Laplace 向基率收缩）。**未用完名额交还 A5**（跨通道套利被影子价格禁止——这正是无套利定理的算法面）。
**参数**：V=10（关键命中价值，画像可调）、c=1、ν 由 A5 边际估计给出。

### A5 边际 VOI 预算分配器（`sea_algo/allocator.py`）

**职责**：每日把 m 个名额分配到通道 {I, II, Q}，使边际信息价值相等（定理 8.1）。
**算法**：
1. 边际估计 rate_c = (近 7 日命中 + 先验·2)/(近 7 日名额 + 2)（收缩到先验表的类 p̂_min）；
2. 边际递减：marginal(c, s) = rate_c · 0.8^s（s=已分配名额；依据：清单内排序质量随深度衰减的实测瓶颈）；
3. 贪心逐名额分配 argmax marginal；
4. **探索底线**：每 3 日每通道至少 1 名额（Red Queen 教训：估计不更新 = 漂移失效；O1 极限环警告采纳与更新的耦合）。
**输出**：(m_I, m_II, m_Q) 与改派日志（S4）。

### A6 次模清单构建（`sea_algo/watchlist.py`）

**职责**：定理 7.3——覆盖函数次模 ⇒ 贪心 (1−1/e)≈0.632 保证；P12 证伪项：贪心/最优比持续 <0.63 即理论被证伪。
**接口**：`greedy_cover(cov, k)`（懒贪心）、`brute_force_optimal(cov, k)`（小实例审计用）。
**粒度**：机构级（实测：机构 0.231–0.269 ≫ 作者 0.02——粒度错误会摧毁 p̂_min）。

### A7 滚动清单管理器（`sea_algo/watchlist.py::RollingManager`）

**职责**：月度重建（A6）+ 漂移监控 + B 类快速审批。
**规则**：
1. 重建窗口 = 最近 2 个月事件覆盖；Jaccard(新, 旧) 记录漂移（月换手实测 0.39）；
2. 新入实体 → **B 类快速审批**：立即进入试用期清单（低配额），S2 签字标记 + 冷却期后转正（个人化修订规程）；
3. 剔除实体 → 保留 30 天影子监测（防止覆盖回归时才发现丢失）。
**诚实注记**：滚动更新的收益是覆盖上限（p̂_min）而非即时召回（阶段三负结果如实继承）。

### A8 抗俘获认证统计量（`sea_algo/certify.py`，O7 首个工程实现）

**职责**：修复引理 12.1 被违背的隐含假设（覆盖与关键性正相关）。原始类覆盖计数被注意力经济俘获（lift 0.63×）；重设计为**质量加权的惊讶度覆盖**：

```
s(e) = Σ_{c ∈ classes(e)} w_c · (1 − r̂_c(entity(e)))
w：regulator 1.0 / wire 0.9 / fin_media 0.6 / tech_media 0.6 / general 0.3 / other 0.2 / aggregator 0.0
   （按实测 p̂_min 序：1.00/0.25/0.15/0.04——权重与类可靠性单调对应；aggregator 归零=不计入认证）
r̂_c(t) = (该实体历史事件被类 c 覆盖次数 + 0.5)/(该实体历史事件数 + 1)   # walk-forward Laplace
认证：s(e) ≥ θ（θ 公开参数，替代原 k_c；k_c 原始计数版冻结）
```

**直觉**：巨头被财经媒体天天报道（r̂→1）⇒ 覆盖贡献→0；一贯沉默的实体突然获得通讯社+监管双覆盖（r̂ 低、w 高）⇒ 强认证信号。**惊讶度是注意力的去偏导数**。
**对抗考量**（O7 后半）：刷覆盖攻击需同时刷高 w 类且保持低 r̂——成本随实体历史长度线性上升；多实体协同刷 ⇒ r̂ 基线整体抬升自动免疫（自稳定）。博弈均衡的完整分析留给 O7 论文项。
**治理不变**：θ 是公开参数，"谁来策展公共层"仍被单参数吸收（§12.1(a) 不受影响）；定理 12.1 的 Ω 下界与认证质量无关，不受影响。

### A9 冲动防火墙与冷却队列（`sea_algo/selector.py::DualChannelSelector`）

**职责**：g¹ 唤起通道的框架层防御（不依赖模型自律——LLM 冲动消费率实测 29–45%，推理型最高）。
**规则**：
1. salience > 阈值的条目**不得直接占用名额**，进入隔离队列；
2. 冷却 τ=2 日后**实质审查再入**：salience 按 0.5/日衰减，再入时以内容效用（而非凡性）参与排序——"睡一觉再买"的算法化；
3. **预先授权白名单**（定理 11.1 Ulysses 契约）：g² 决策集声明的紧急类（如"持仓公司重大披露"）旁路防火墙，但强制写 S4 审计条目 + 事后复盘；
4. 白名单本身只能经 S2 签字修订（防火墙的防火墙）。

### A10 校准层 θ_cal（`sea_algo/calib.py`）

**职责**：预测 calibration 的纵向追踪（H9）+ 重校准 + 家族策略查表。
**组件**：
1. `ThetaCalTracker`：滚动窗 Brier/ECE（窗口 30 预测）；漂移报警（ECE 连续两窗 >0.25 ⇒ 降级该模型的自动权重）；
2. `Recalibrator`：PAVA 等渗回归（保单调——H9 判定条款"允许系统偏移，须单调可校正"的算法兑现）；
3. 家族初始化策略（先验表）：推理型（Brier 0.170）直接使用；qwen 系（0.231）轻校准；gemma 系（0.279，差于常数基线）**强制重校准 + 置信上限 0.9**。
**主权约束**（命题 10.2）：θ_cal 的人类侧测量不可由机器代做——AI 队列的 θ_cal 是转移桥锚点，不是人类校准的替代。
