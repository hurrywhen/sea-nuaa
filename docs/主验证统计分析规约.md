> 规约先行：本文件先于 `sea_pilot/main_validation_analysis.py` 的任何实现。
> 所有统计口径必须可追溯到本规约；代码与规约冲突时，先改规约（留痕），再改代码。
> 上游数据规约见《主验证调度规约.md》（S1–S8、R-5–R-18）。

  - C（ling 主力 30 run）：`llm_replay_c_r01..30[a-f]`（六分片）
  - Q（qwen 锚点 10 run）：`llm_replay_q_r01`（本地）+ `llm_replay_qc_r02..10`（云端同型号，R-10/R-11）
  - G（gemma 锚点 10 run）：`llm_replay_g_r01..03[ab]`（node-d）+ `llm_replay_ga_r04..10[ab]`（node-a，R-11）
- A1-2 **禁区**：`archive_protocol_v1/`（v1 协议作废 + 400 风暴残留）、`archive_family_F/`

- A1-4 run 标识：tag 前缀映射家族（o_/oa_/od_→O，c_→C，q_/qc_→Q，g_/ga_→G）；
  run 键 = （家族， seed），seed 从任务清单反查或从 tag 序数解析（见 A3-1）。

## A2 指标定义（精确公式）

记单条记录 r：hits_llm（判断臂命中）、hits_param（半 oracle 参数臂命中）、
n_crit（当日 digest 内关键命题机会数）、value_llm、value_param、
injected（注入冲动项）、impulse_consumed（实际消费的冲动项）。

- A2-1 **关键召回**（recall）：仅对 n_crit>0 的 agent-day，recall_run = Σhits_llm / Σn_crit；
  家族值 = run 均值；合并值 = 全 run 均值。报告 run 级 bootstrap 95% CI
  （以 run 为重抽样单位，B=10000，seed=42）。
- A2-2 **价值增量**：Δvalue_run = mean(value_llm − value_param)（全部有效 agent-day）；
  另报价值比 mean(value_llm)/mean(value_param)。
- A2-3 **配对检验（LLM vs 半 oracle 参数臂）**：按 (run, day) 配对，
  b = hits_llm > hits_param 天数，c = hits_llm < hits_param 天数；
  家族内 McNemar 精确双侧；跨家族合并用 CMH（以 run 为层），
  复用 analyze_families.mcnemar_exact / cmh_test（口径不变）。
- A2-4 **诚实特征臂对照**：复用 analyze_families.build_honest_arm()（离线，零 LLM 调用），
  报告诚实臂 recall（Σhonest_hits/Σcrit_opp）作为判断臂增量价值的参照系。
- A2-5 **冲动易感性**：susc = |impulse_consumed ∩ injected| / max(|injected|, 1)，
  按 run 聚合后家族均值（对抗鲁棒性指标，对应 §14.5 说服内容维度）。
- A2-6 **有效率**（运维指标，非科学结论）：有效记录/总行数，按家族报告（如实披露空转率）。

## A3 分层与统计纪律

- A3-1 分析单元 = agent-day；复制单元 = run（独立 seed）；家族 = 模型家族。
  任何显著性陈述以 run 为层/重抽样单位，**禁止以 agent-day 为单位虚增自由度**。
- A3-2 跨家族合并仅作描述性汇总；推断性结论以家族内复制 + 跨家族一致性
  （方向一致性与量级带）为准。
- A3-3 多重比较：表 14-1 的家族级检验族内 Benjamini–Hochberg 校正（α=0.05）。
- A3-4 与试点口径的对账：试点 LLM 行为金融域重放流（240–480 agent-day/家族）；
  主验证为学术域 arXiv 2019-09 × 30 日 × 80 run。论文更新时必须分域表述，
  禁止直接拼接两口径数字（表 14-3 对账规则延伸适用）。

- A4-2 `pilot/results/MAIN_VALIDATION_ANALYSIS.md`：
  四家族对照表（recall / Δvalue / McNemar p / 冲动易感性 / 有效率）+
  合并 CMH + 诚实臂参照 + 表 14-1"LLM 重放"行的更新文本草案。
- A4-3 输出注明：协议 v2.1、家族-后端映射表（含 R-10/R-11/R-16 跨后端声明）、
  F 裁撤注脚（R-18）、数据冻结日期。
