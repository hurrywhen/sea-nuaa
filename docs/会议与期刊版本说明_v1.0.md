# SEA 会议版与期刊版说明（v1.0）

本目录中的两套新稿由英文主稿 `input/sovereign_epistemic_acquisition_EN_v1.7.md` 拆分、压缩而成；中文稿为同步镜像。它们不是新的实验报告，不改变任何冻结实验数值，也不替代 v1.7 专著稿及其审稿回复。

## 1. 版本分工

| 版本 | 科学主线 | 理论/证据分工 | 通用版式与页限 |
|---|---|---|---|
| 会议版 | LLM 智能体作为判断层机制研究的模式生物：四家族重放及两域适用边界 | 仅保留理解实验所需的 SAP、双通道与两个结构性判据；完整证明交由期刊版/专著稿 | 通用 `IEEEtran` 双栏；**总 PDF ≤6 页，含参考文献**；不代表已选定 IEEE 会议 |
| 期刊版 | 主权认知获取问题（SAP）的统一形式框架与核心定理链 | 核心定义、定理与证明为主体；两域与四家族结果仅作精选验证和边界映射 | 通用 `article` 单栏 A4；目标 **28–32 页（约 30 页）** |

两稿的有意分工是“理论主文”与“机制验证主文”，不是把同一篇稿件简单改名后重复投稿。正式同时投出前，作者必须按两个收件载体的政策披露相关稿件/预印本，并确认重叠范围、并行投稿和会议—期刊扩展规则。

**署名顺序（2026-10-25 调整）**：会议版为 **Xutong Wang（王绪彤）、Wen Hu（胡文）、Ya Yu（于雅）**；期刊版与专著版保持 Wen Hu、Xutong Wang、Ya Yu。通讯作者仍为 Wen Hu，CRediT 角色内容不变。

## 3. 构建与检查

依赖：pandoc ≥3、XeLaTeX、`IEEEtran`（英文会议通用版）、完整 DejaVu 字体变体、Noto CJK（中文）、Poppler（`pdfinfo`/`pdftotext`）。完整 DejaVu 的默认查找路径为 `~/.local/share/sea_fonts/dejavu`，可用 `SEA_DEJAVU_DIR` 覆盖。

```bash
# 英文会议版（硬检查 ≤6 页）或英文期刊版（目标 28–32 页）
bash tools/build_venue_pdfs.sh conference
bash tools/build_venue_pdfs.sh journal

# 中文镜像；en/zh/all 可批量构建
bash tools/build_venue_pdfs.sh zh

# 四稿的来源一致性、证据状态与 PDF 文本层检查
python3 tools/audit_venue_papers.py

# 重新生成页数、表格、公式和 SHA-256 清单
python3 tools/make_venue_manifest.py
```

`tools/venue_tex_postprocess.py` 将 pandoc 的短 `longtable` 转为双栏可用的 `table* + tabular`；会议版只使用短表。完整长表、逐 run 记录和审计方法仍留在公开仓库及专著补充材料中。

## 4. 不变的证据边界

- 已完成证据是两域真实语料试点和四家族 LLM 智能体判断层机制重放，不是总体层面的人类验证；完整 P1–P12 仍在进行中。
- 学术域强形式高召回被拒绝（最佳端到端召回 0.28）；金融域 0.952 仅属于高度有利的组合内、配额匹配设置，新闻层扩展后降至 0.910。
- 四家族判断臂召回为 0.443/0.534/0.514/0.519，均高于诚实特征臂 0.241；但价值增量并非跨家族一致为正。
- 迄今**零人类被试数据**。HP-0 保持“已设计；数据收集待完成”；所有人类侧结论均为可证伪预测，而非已证实结果。
- 具体定理只在各自假设下成立；猜想、条件性设计引理和已证明定理不得混写。

## 5. 选定会刊后的必要适配

1. 以官方模板替换通用版式，重新核对页限是否含参考文献、图注和附录；
2. 双盲场馆另制匿名稿，移除作者、单位、可识别仓库和自引身份；当前为署名版；
3. 按场馆要求准备 CRediT、ORCID、利益冲突、伦理、AI 使用及相关投稿声明；
4. 检查参考文献格式、图表分辨率、补充材料入口和匿名/署名仓库不得混用；
5. 每次改稿后重新运行对应构建与 `tools/audit_venue_papers.py`，并保存最终 PDF 的页数和 SHA-256 清单。
