# SEA v1.12 最小有效实验包（协议草案，未执行）

> **状态：设计稿，不是实验结果，也不是公共注册。** 本文件用于替换“已有判断层重放可以识别 SEA 整体效果”的错误证据叙事。只有在时间戳注册、数据冻结、全部主要臂执行和不可变发布完成后，才可把相应分析称为前瞻确证。

## 1. 识别问题与主要估计量

### 1.1 需要识别的效应

比较的不是“某个 LLM 是否会选好文章”。**唯一主要比较**是在模型、原始候选流、检索权限和推理预算相同的条件下，完整 SEA（S2）相对于同模型端到端筛选（S2d）的增量效果。**唯一主要结局**是从原始候选流开始、按全分配失败复合规则计算的“未获得有效阳性操作性消费测量”的加权遗漏

\[
\mathcal M_{\nu,a}^{FC}=\sum_j \nu_j Y_{aj}^{FC},\qquad
Y_{aj}^{FC}=1\{\text{没有任何通道给出有效阳性操作性消费测量}\}.
\]

理论潜在真实消费遗漏仍记为 \(\mathcal M_\nu\)，不得与 \(\mathcal M_\nu^{FC}\) 混用。对每个分配目标—运行，只有有效阳性 operational attendance 测量记 \(Y^{FC}=0\)；明确未消费、合法 abstention 和终端结局 unknown 均按主规则记 \(Y^{FC}=1\)。原始 attendance 测量失败仍保留为 `unknown`，不得改写成观测到的未消费。该估计量不等同于恢复测量失败者的潜在真实消费。

不得用固定摘要后的条件召回或非空 `picked` 记录替代。RAG 安全管线（S4）、福利优化推荐（S5）、其他消融、预声明决策价值和效率均为分层次要分析；不存在多个主要结局。引用量只可作为单独的学术影响代理，不得改称 SEA 价值或福利；召回提高而价值降低必须同等报告。

### 1.2 估计量口径

每个结果必须给出：目标集版本、抽样测度、消费单位（文档／命题／公司—日等）、原始流规模、上游遗漏、各通道分子与分母、运行级聚合规则。所谓“覆盖”至少拆成：

\[
A_i(e)\ \text{参考可用}\rightarrow L_i(e)\ \text{链接}\rightarrow Q_i(e)\ \text{选择}
\rightarrow \Delta_i(e)\ \text{投递}\rightarrow O_i(e)\ \text{打开}\rightarrow Z_i(e)\ \text{操作性 attendance},
\qquad D_i(e)=A_iL_iQ_i\Delta_iO_i\Gamma_i.
\]

其中 \(Z_i\) 是操作性测量，\(\Gamma_i\) 是潜在真实消费；二者不得混同。对每一来源类别×每一目标命题保存这些阶段指标。`picked` 只对应 \(Q_i\)，不能推出 \(\Delta_i,O_i,Z_i\)。原始阶段未测量写 unknown，不得自动写成 0 或 1；第 1.5 节的失败复合编码只用于主要结局分析，不改写原始测量。类别增量恢复率只作条件恢复描述，不能改名为相互独立或 \(k_{\mathrm{eff}}\)。名单联合覆盖已经是并集结果，不得再取 \((1-p_{\min})^{k}\) 重复计算冗余。

### 1.3 目标集构造、参考可用性与版本规则

- 目标集由冻结的构造规则产生，保存命题规范文本、构造证据、权重、候选—目标映射 \(\mathcal T_v\) 和参考语料快照哈希。主要目标应由独立评审在结果发生前标注；当前仓库只提供合成规则一致性示例和空白盲法标注模板，不冒充已完成人工核验。
- “真实可用”定义为参考语料快照中的可用事件 \(A^{ref}\)，必须有内容哈希、来源指针和可用时间窗。封闭快照中的缺席只能称 `unavailable_in_closed_snapshot`，不能推断开放世界不存在。
- 目标集或映射版本变更创建**新的 SAP 实例**（`NEW_SAP_INSTANCE__NO_CROSS_VERSION_POOLING`），不得跨版本合并估计。命题合并／拆分必须同时说明权重和终端事件如何对齐；否则是不同估计量。
- 报告评审间一致性、仲裁规则和合并／拆分敏感性。合成示例中细粒度遗漏 0.5、粗粒度 ANY 成员消费遗漏 1/6，说明粒度不可默认不变。

### 1.4 分语料域的 attendance 测量工具注册

在解锁处理臂结果前，必须为每个语料域冻结 `instrument_registry`，包含工具名称与版本、原始事件 schema、阳性／阴性判定规则、阈值、验证集与代码哈希、测量误差、替代工具和敏感性阈值。没有完成注册和验证的域不能进入主要分析。

- **学术／新闻等数字文本域：**主要判定规则必须明确为 **AND**：\(Z=1\) 当且仅当 (i) 有效阅读事件（聚焦可见、有效参与时长、内容覆盖均达到冻结阈值）**且** (ii) 内容相关主动确认或任务相关操作成立。单独打开、点击、停留、滚动或仅满足其中一项不能判为阳性。完整有效测量但不满足 AND 记操作性阴性；测量缺失或无效记 unknown。阈值 \(\tau_{dom}\) 由独立测量验证集估计，以处理臂盲法的人工参考标注为参照，冻结后方可读取比较结局；不声称存在通用秒数阈值。替代工具（仅阅读、仅确认、仅任务操作）和阈值敏感性须预先注册。
- **金融／决策任务域：**除上述有效阅读事件外，任务相关操作可包括与内容哈希绑定的批注、保存到决策工作区、或将该内容引用到预声明决策输入。仅下载、通知送达或无内容引用的后续点击不算 attendance。
- **机器到机器的私域语料：**可使用“完整内容哈希进入声明的下游任务上下文＋下游任务操作引用该回执”的组合事件，并用合成阳性／阴性 fixture 验证遥测。该结果只能称 `machine_ingestion_and_task_reference`，必须与人类注意分开报告；它不证明内容实际影响下游计算，也不能据此推断人类学习或福利。
- 若后续加入音频、视频或其他介质，必须先另建并验证域专用工具，不得套用文本阈值。

主要工具的替代版本至少包括：仅主动确认、仅有效阅读事件、仅任务相关操作，以及 \(\tau_{dom}/2,\tau_{dom},2\tau_{dom}\) 的阈值敏感性；所有版本在解锁前固定并完整报告，不得按有利结果挑选。负责参考标注、 attendance  adjudication 和测量验证的人员须对处理臂、模型家族和比较结果盲法；自动判定代码也须在注册时冻结。测量缺失、遥测无效、工具崩溃或评审无法判定时，原始 attendance 必须为 `unknown`。

### 1.5 唯一主要缺失结局规则与敏感性地位

主要分析采用**全分配失败复合规则**，不是 complete-case、逆概率加权或多重插补：

1. 至少一个通道有有效阳性操作性 attendance：主要遗漏指标 \(Y^{FC}=0\)。
2. 有效完成测量且明确未消费：\(Y^{FC}=1\)。
3. 预注册的合法 abstention：属于处理策略结局，留在全分配分母并记 \(Y^{FC}=1\)，不是缺失。
4. 解析、运输、重试、执行或 attendance 工具失败导致终端结局未知：原始值保留 `unknown`，主要复合结局记 \(Y^{FC}=1\)。

所有分配目标—运行均进入主要分母，权重和聚合层级在解锁前固定。失败复合编码对单臂遗漏水平是保守端点，但**不保证两臂差值方向保守**；必须按处理臂×阶段×原因公开测量失败率。

令 \(u_a=\sum_j\nu_j1\{\text{臂 }a\text{ 终端结局 unknown}\}\)，主要差值 \(\Delta^{FC}=\mathcal M_{\nu,sea}^{FC}-\mathcal M_{\nu,control}^{FC}\)。在不假设缺失机制的情况下，潜在遗漏差值的 sharp 边界为
\[
\Delta^{FC}-u_{sea}\ \le\ \mathcal M_{\nu,sea}-\mathcal M_{\nu,control}\ \le\ \Delta^{FC}+u_{control}.
\]
下界对应 sea unknown 全按潜在成功、control unknown 全按潜在失败；上界对应反向赋值。两个臂别极端情形必须同时报告，不能只给“unknown 全成功”的单臂最佳情形。

敏感性分析须完整并列：(a) unknown 全部按已消费的最佳情形；(b) 使用解锁前冻结的处理臂感知缺失模型和协变量作逆概率加权；(c) 如有额外可辩护假设，预先规定的多重插补。complete-case 只作描述，绝不成为主要分析。不得在查看结果后选择缺失规则，也不得在“缺失”与“合法 abstention”之间重新归类以获取有利结论。

## 2. 语料与时间外设计

### 2.1 独立环境

至少使用：

- 三个互不重叠的时间窗口；窗口之间不共享目标命题、训练特征或调参结果；
- 两个语义与来源结构不同的语料域；
- 至少一个模型知识截止之后新产生的语料，或一个带访问控制的私域语料；
- 至少一个完全保留给最终评估的锁定语料。所有配置、提示词、阈值与排除规则在解锁前冻结。

80 个配置共享一个 30 天语料只能算一个环境。推断的主单位是**独立语料／月份**，不是 agent-day。agent、日和 run 只用于描述环境内变异。三个时间窗口和两个语料域只是最低覆盖要求，不能替代基于独立环境数、环境间方差、组内相关、缺失率和主要端点的功效模拟。

### 2.2 严格 point-in-time 快照

为每个文档保存：原始发布时间、首次抓取时间、接收时间、版本时间、可见权限和特征计算时间。只允许使用决策当时已经可获得的字段。URL 日期不能单独证明可用性；EDGAR 接收时间还需经过预声明的盘前／盘中／盘后规则。

禁止把 2026 年获取的历史引用量、后续市场结果或事后整理名单作为 2019 年当时可知特征。事后结果只能用于明确命名的代理标签，且必须与事前标签分开。

### 2.3 事前目标集与泄漏审计

- 主要目标由独立评审在结果发生前依据决策任务标注；报告评审间一致性与仲裁规则。
- 引用量、市场波动日等事后标签仅进入次要代理分析，不能写成“事前个人决策关键性”。
- 标题与作者匿名化，保留必要的主题和内容信息；另设非匿名记忆诊断臂。
- 对模型记忆实施精确字符串、规范化字符串、标题—作者组合和语义改写匹配审计，公开匹配阈值、人工复核和命中处置。
- 记忆命中不能靠删除结果美化；主分析按预注册规则报告保留、剔除与敏感性三种结果。
- 检索系统也需记录索引快照与更新日期，防止供应商侧未来信息进入。

## 3. 处理臂与公平比较

所有臂共享同一原始候选流、知识状态、决策声明和实际消费预算。模型实例、量化、提示上下文、工具权限、检索索引、最大输入 token、推理 token、重试次数和成本上限均匹配或作为预先声明的正交因素，不得与家族或处理臂混杂。

| 臂 | 必要内容 | 识别目的 |
|---|---|---|
| S0 | 原始流按时间消费 | 最低参考 |
| S2 | 完整 SEA：监测、双通道、命题归并、统一预算、审计 | 待评结构 |
| S2a | 去除 pull | pull 的增量 |
| S2b | 固定预算分割 | 联合预算的增量 |
| S2c | 去除监测直通，仅评分 | 监测结构的增量 |
| S2d | 同一 LLM 直接对原始流端到端筛选和排序 | 结构与模型判断的区分 |
| S4 | 同模型 RAG＋安全过滤，明确检索器与 top-k | 对当前工程基线的增量 |
| S5 | 同信息权限的福利优化推荐 | 对非主权福利目标的增量 |

完整消融必须包含：命题归并、监测清单、来源冗余、统一预算、目标写入／审计界面。不得以“上游固定摘要相同”冒充 S2d；S2d 必须从原始候选流开始。

## 4. 抽样、盲法与预注册

1. 在解锁定语料前，以带时间戳的公共注册库冻结：假设、主要臂、主要结局、目标集、样本量、排除规则、缺失／冲突处置、统计模型、多重性和发布清单。内部冻结文件只能称 internal frozen protocol。
2. 在独立语料数量上作功效模拟，不能以数万个相关 agent-day 夸大有效样本量。报告最少独立月份／语料数及其功效假设。
3. 目标标签评审、attendance 参考标注／ adjudication、测量验证和结果审计必须对处理臂、模型家族及比较结局盲法；自动判定版本在解锁前冻结。确有结构性原因无法盲法时，不得将相应人工判定作为主要测量；必须披露并更换流程，或把相应结果降为敏感性分析。
4. 配置与随机种子在结果生成前分配；模型版本和后端改变视为新实验层，不能事后只保留有利后端。
5. 主要分析只使用锁定语料一次。查看结果后的唯一键修复、分段、替代标签和新机制分析一律标为探索性。

## 5. 统计分析规约

### 5.1 主要模型

- 以语料／月份为最高推断单位；优先报告每个独立环境的效应及环境间区间。
- 环境内层级模型可包含 run、agent、日，但不能把其自由度当成独立环境数。
- 小环境数时报告随机化推断、环境级符号翻转或 wild cluster bootstrap 的适用条件与局限；不只给极大样本正态近似的微小 p 值。
- 唯一主要结局先检验；主要结局与分层次要结局采用预先声明的 gatekeeping。召回和价值不得互相替代。探索性异质性和机制分析单独标记，不与主要检验族混用校正。

### 5.2 平均召回的置信口径

若 \(E_1,\ldots,E_n\overset{iid}{\sim}\nu\)，令 \(Y_j^{FC}=1\) 表示没有监测来源给出有效阳性操作性消费测量，则 \(Y_j^{FC}\) 直接估计失败复合加权平均遗漏 \(\mathcal M_\nu^{FC}\)，不等同于潜在 \(\mathcal M_\nu\)。此时可使用 Bernoulli 均值的精确区间或有界变量区间；该区间针对 \(\mathcal M_\nu^{FC}\)，不是 \(\inf_e q_S(e)\)。跨多个配置的报告须预先分配同时置信水平。

若命题按日、事件或语料聚类，独立抽样假设不成立，应改为独立 cluster 抽样或使用与设计一致的 cluster 区间。对一个完整有限语料的描述性召回不需要假装存在超总体区间；对未来命题的保证必须另建明确超总体模型。

### 5.3 点态界（仅附加分析）

只有在额外假设真的成立时才报告逐命题界：逐类别×逐命题条件覆盖概率模型、联合独立模型、同时置信下界以及实际消费转换模型。有限样本“没有拒绝独立”不等于独立成立；两来源的增量覆盖不等于独立子集基数。无法识别时，主文只报加权平均结果。

### 5.4 缺失、重复与冲突

- 唯一键、原始行、重复、空输出、缺失和冲突分别记账；不按首行／末行或有利结果仲裁。
- 主要分析严格执行第 1.5 节的全分配失败复合规则：合法 abstention 留在全分配分母且消费失败；解析、运输、执行和测量失败的原始终端结局保留 `unknown`，主要复合结局记遗漏。不得把所有 `picked=[]` 统一删除或统一追认为合法 abstention。
- unknown 按已消费、冻结模型的逆概率加权和预注册多重插补仅为敏感性；不存在看到结果后切换主要估计量的选项。
- 指标级充分字段完全一致才归并，冲突按预注册规则处理；分子、分母和可用案例随每个结果公开。
- 缺失机制分析和完整情景矩阵必须与主规则同时发布；不得只报告有利端点。

### 5.5 效率与资源结局

每次运行记录模型／工具调用、输入／输出 token、计算量、费用、墙钟时延和重试；同时报告每运行总量与每成功实际消费目标的比率。零消费目标的比率记 undefined。上述指标必须来自日志，不得用 agent-day 或列表长度反推。历史重放缺少这些字段，因此不能补写效率优势。

## 6. H8/H9 人类迁移门槛

当前论文选择条件性设计／审计路线，人类 RCT **不是**本文投稿或公开快照的前置条件；只有未来提出人类学习、福利或迁移主张时才必须执行直接人类研究。

1. 门槛按**模型家族×版本×任务**逐一判定；必须在运行前冻结全部必需 paradigm、方向、效应区间、最低样本和失败处置。
2. 只有全部必需项目通过，才允许把该家族用于人类侧参数外推；任何一项失败或不可判定，该家族只能用于 AI 自身机制描述。
3. 现有重放未满足该条件：反对暴露方向跨家族不一致；准确性提示在三个具名家族中方向均为负，但一家接近零且不在目标效应区间；H9 的多个参考带不可通约。因此现有全部家族均不得用于人类外推，所有 H8 结果只能作为 AI 任务描述，辨别材料也不能据此称为无记忆污染。
4. Brier 不是纯校准指标。未来 H9 使用同题集、同期限、同基准率的人类—模型配对，报告 Murphy 分解中的 reliability、resolution 和 uncertainty；不得把 0.112 与不同研究的 0.15–0.21 混为一个“human band”。
5. proper scoring rule 的真实报告性质只在指定效用和激励条件下成立；预测平台排名、奖励和战略动机必须单独建模。

## 7. 人类实验的设计数字（仍未执行）

标准正态近似、\(d=0.35\)、双侧 \(\alpha=0.05\)、power=0.8 时，未校正 \(n=128.145\)（独立向上取整为 129）；直接对未校正的 \(n/(1-0.25)=170.860\) 向上取整，按 25% 脱落校正应为 **171／组**。171 不是把已取整的 129 再除以 0.75（那样会得到 172），而是分别对两个未取整公式取整。

- 若只声明一个主要比较：三臂总计 **513**，其余比较列为次要并控制多重性。
- 若声明 C-vs-A 与 C-vs-B 两个共同主要比较，Bonferroni 敏感性计算为约 **207／组**、总计 **621**。

这些只是协议功效计算，不是人类数据，也不替代基于纵向混合模型、真实脱落和基线方差的正式功效模拟。HP-0 仅检验流程可完成性，不能检验效果。
