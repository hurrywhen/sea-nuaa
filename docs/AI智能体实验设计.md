# AI 智能体队列实验：主验证载体设计（工作文档）

日期：2026-09-26 · 状态：讨论稿 v0.1 · 关联：论文 v1.0 §14–§15、`docs/LLM模拟人类_可行性与边界.md`、`docs/典型画像_参数标定.md`、`docs/数据源与公开数据库清单.md`

**战略定位（2026-09-26 团队决定）**：本理论是对"一切有限智能体"陈述的（公理 1–6、不变量 I1–I5、对称表 §3.3/§9.3），实验主对象相应转为 **AI 智能体队列**；人类数据只用可在线低成本获取的公开资源，作为外部锚点，**不做任何人类招募与访谈**。

## 1 模式生物论证：AI 智能体作为主实验对象买到了什么

| 维度 | 人类 RCT | AI 智能体队列 |
|---|---|---|
| 时间 | 12 周墙钟 × 510 人 | 90 模拟日 ≈ 数小时—数天（时间压缩），可千次重复 |
| 地面真值 | 不可观测（关键性、操控强度只能事后评审） | **全反事实可观测**：$v^*, m, s$ 就是生成器参数；历史重放中"未来"已知 |
| 统计功效 | n≈170/臂，流失 25% | n=数百—数千 runs/臂，零流失 |
| 成本 | 百万元级 + 半年 | token 成本 $10^3$–$10^4$ 量级 + 数周（§9 估算） |
| 伦理 | IRB + 招募 + 知情同意 | 仅红队内容生成需安全审查 |
| 可复现性 | 低（人不可复制） | 高（固定种子 + 固定模型版本 + 环境快照） |
| **买不到的** | — | 人类特含量：真实情绪 $\delta_{\mathrm{human}}$、经练习的德性形成、真人福利效应 → 由在线锚点 + 推迟的 RCT 承担（论文 §15.3/§15.5） |

**理论侧的合法性**：全部核心定理的数学对象（预算约束、覆盖事件、权重漂移度量、门控延迟、遗憾界）不引用任何人类特有属性；§3.3 对称表逐行给出 AI 实例化（容量=上下文与推理预算、俘获=提示注入、溯源=签名凭证、反思层=委托人授权配置、德性=校准度+稳健性+过自信惩罚）。因此**在 AI 智能体上检验这些定理不是退而求其次，而是对理论普适性主张（C1）的直接检验**：若定理只在人类身上成立而在 AI 智能体上失败，普适性主张本身就被证伪。

**一个漂亮的自指印证**：命题 10.2（去技能化不可能三角）的 AI 实例有独立文献支撑——只消费其他模型的加工输出会导致递归退化（model collapse，Shumailov et al., 2024, *Nature*）："机器负责到达、人（委托人代理）负责在场"在 AI 侧对应"摘要层负责到达、原始证据层负责校验"。H7'（下）直接检验它。

## 2 实验主体规范

### 2.1 三层主体

1. **参数化主体**（$10^4$，论文 §14.2 原设计）：便宜、方差可控，承担人口级统计与生态动力学（$\sigma^*$ 相变、$\Omega$ 下界）；
2. **LLM 智能体队列**（100–1000 个，**主实验主体**）：完整运行 SEA 栈（评分、双通道选择、Pandora 探索、EIG 查询、 Whittle 调度、课程门控、紧急覆盖），承担 H1'–H7' 的行为学检验；
3. **混合主体**：参数化外壳 + LLM 决策核（仅关键决策/操控暴露时调用），用于大规模与真实感的折中臂。

### 2.2 智能体架构（每个 LLM 智能体）

```
感知（环境接口：当日候选池、监测清单投递、公共层）
  → K（知识状态：命题图记忆 + 已消费集 + 信念库）
  → 决策核（评分 ⟨w,φ⟩、双通道准入、pull 算子选择、边际 VOI 调度）
  → 行动（消费/摘要阅读/原文阅读、查询、探索、预测提交、紧急响应）
  → θ 测量（周期性校准任务 + 信念修正任务 + 过自信惩罚项）
  → 日志（全决策留痕：S4 的实验版本）
```

- **persona 卡**：五画像（医生/投资者/研究者/企业主/公民家长）× 数字痕迹生成（知乎职业话题、Reddit 职业版、公开自述材料——**零访谈**，见画像文档）：决策集 $D$、$g^{(2)}$ 概要、预算 $T$（token/调用次数双计价）、初始 $\theta$、监控清单模板；
- **委托人代理（反思层 $R$ 的实验实现）**：每画像一个"宪法文件"（constitution：批准规则、$D_{\mathrm{adv}}$、课程门控策略），由团队维护；慢尺度提议按宪法自动批准/否决 + 抽样人工复核——这是"人类门控"在零招募约束下的合法实现（门控的**形式功能**被保留：更新须经外部权威规则，不由系统自定）；
- **$g^{(1)}$ 冲动项注入**：LLM 无内脏冲动（`LLM模拟人类` 文档 §2），框架层按画像相关概率临时抬高唤起维度权重/诱导即时效用错配；注入参数从在线人类数据锚定（MIND 点击分布 = $g^{(1)}$ 的公开代理）。

### 2.3 模型分离原则（防循环性，强制）

**主体模型 ≠ 评分器模型 ≠ 生产者/红队模型 ≠ 评审/归并模型**，至少 3 个模型家族。理由：同族模型误差相关会使"评分器认为重要 = 主体认为重要"成为同义反复，召回与 $d'$ 测量失效。评审模型（命题归并 $\kappa$、覆盖判定）另加人工抽检 10%（团队执行，S4 精神）。

## 3 实验环境

### 3.1 合成生态（论文 §14.1 四层生成器）

全地面真值；用于 P1–P12 中机制类命题与生态动力学（$\sigma^*$、$\Omega$、Red Queen）。

### 3.2 真实语料时序重放（外部效度的主载体）

按真实时间戳重放历史流，**结果已知 ⇒ 预测任务零标注成本**（回溯预测法）：

| 重放流 | 数据源（见数据清单文档） | 服务画像 | 地面真值 |
|---|---|---|---|
| 财经新闻流 | GDELT 财经 + 巨潮/EDGAR 披露事件表 | P2 | 披露事件 = 关键命题清单；市场反应（First Call ⚠） |
| 大众新闻流 | News2016zh / GDELT 中文 + 热榜存档 | P5、P4 | 辟谣平台存档 = 谣言真值；重大事件清单 |
| 学术流 | arXiv 类目日馈 + Semantic Scholar 引用 | P3 | 高被引 = 事后重要性；单源性直接可测 |
| 医疗流 | WHO DON / ProMED + FDA/NMPA 警示时间线 | P1 | 官方警示 = 关键事件真值 |
| 谣言风暴事件 | Weibo21 传播树 + PHEME | P5 压力测试 | 谣言/真实标签 + 协同结构 |

重放协议：按日推进；智能体只见"当日及以前"的内容；预测题从"当时未决、现已知结果"的事件池抽取（如重放 2019 年流，问"该政策 30 日内会否落地"——答案已在历史中）。

### 3.3 对抗环境

- **提示注入臂**：BIPIA/InjecAgent/TensorTrust 风格载荷注入内容流（$\delta_{\mathrm{AI}}$、$\rho_m$ 直接标定）；
- **说服内容臂**：Persuasion 数据集技术类型 × 唤起度梯度的内容（LLM 可被说服性有文献记录，效应可测）；
- **协同造假臂**：Weibo21 谣言级联重放 + 合成生态的伪独立多类攻击（$k_{\mathrm{eff}}$ 攻防）。

## 4 处理臂与实验矩阵

- **策略臂**（论文 §14.3）：S0 原始流 / S1 参与优化 / S2 完整 SEA / S2a 仅 push / S2b 固定划分 / S2c 纯评分 / S3 时序可信；
- **因子**：策略 × 画像（5）× 环境（合成 + 2–3 条重放流）× 对抗强度（0/低/高）；
- **规模**：全因子太贵 ⇒ 主效应设计：每画像每策略 ≥ 30 个智能体 run × 90 模拟日；对抗与消融在子矩阵上跑；总 run 数 ~2000–5000（参数化主体承担 $10^4$ 级生态臂，LLM 智能体承担行为臂）。

## 5 测量与 KPI

对应论文 §13 的 P1–P12 全部可在智能体上测量（真值已知使 P2/P3/P5/P9 从"审计"升级为"精确测量"）。新增智能体侧 $\theta$ 测量：

- $\theta_{\mathrm{cal}}$：回溯预测 Brier/ECE 轨迹（每 10 模拟日一批）；
- $\theta_{\mathrm{open}}$ 的 AI 类比：证据条件化信念修正率（给新证据后立场更新幅度 vs 应然贝叶斯幅度）；
- 过自信惩罚：置信度—正确率缺口的非对称项；
- $q_t$ 类比：原文/原始数据触达率（vs 只读摘要）——H7' 的自变量。

## 8 效度威胁与对策

| 威胁 | 对策 |
|---|---|
| LLM 偏差（过度合规/过度理性/同质化/persona 漂移） | 冲动项外生注入；框架层预算强制；多基座混用；一致性重测（继承 `LLM模拟人类` 文档 §5） |
| 循环性（为 AI 设计、在 AI 上自证） | 模型分离原则（§2.3）+ 真实语料地面真值（§3.2）+ 人类锚点（H8/H9） |
| 模型版本漂移 | 版本冻结 + 锚点重跑；结论标注模型世代 |
| persona 是"拟像"而非真实职业者 | 数字痕迹锚定 + persona 一致性测试 + 结论限定为"persona 条件化"；人类侧转移由对称表 + 锚点承担，**不宣称已验证人类效应** |
| 成本失控 | 事件驱动调用 + 决策缓存 + 参数化主体承担生态臂（§9） |

## 9 成本与时间表（量级估算）

- LLM 行为臂：~300 智能体 × 90 模拟日 × 事件驱动 ~15 调用/日 × ~1.5k token ≈ 0.6 B token/全队列轮次；廉价模型 ~$10^2$/轮，强模型 ~$10^{3.5}$/轮；处理臂 × 重复 ≈ 10–20 轮 ⇒ **$10^3$–$10^4$ 量级**，对比人类 RCT 的百万元级；
- 墙钟：并行化后单轮数小时—2 天；全部 H1'–H9 预计 **8–12 周**（含环境搭建与锚点验证）；
- 人力：2–3 名工程师/研究者，无招募、无 IRB 关键路径（红队内容生成走机构安全审查）。

## 10 零招募清单（本方案砍掉与替换的人类环节）
