## 深度解读（2026-09-27 首跑）

1. **范式 B 的方向通过但机制不同构**：treatment 极端度上升（d=0.36，与 Bail 2018 人类效应量 0.22–0.35 同带），但 LLM 的同时出现了人类实验中罕见的**大幅同化**——带符号位移 treatment=-1.17 vs control=-0.17（7 点量表上被对立论据说服移动 >1 分）。人类在 Bail 范式中是『抵抗并极化』，LLM 是『被说服并顺带推高端点分布』。**含义**：LLM 智能体对论据型说服的易感性系统性高于人类（谄媚/说服敏感是已知模型特性），对唤起型操控则无对应通道——`docs/LLM模拟人类` §2 预言的双向失真**首次被实验证实**；δ 的 LLM 测量值不可直接用作人类先验，论据型载荷须向下修正、唤起型载荷须由文献先验承担。
2. **范式 A 方向失败的机制是地板效应+机制缺席**：control 臂假内容分享意愿已低至 1.67/10（人类基线通常 4–5/10），无下压空间；提示的作用表现为真内容分享上升（辨别差 4.79→6.90）而非假内容下降。人类文献中准确性提示起效的前提是『注意力疏懒』（Pennycook: lazy, not biased），LLM 无此失效模式。**含义**：准确性提示类干预的效应量不得从 LLM 仿真外推到人类；仿真中该干预应标记为『机制缺席』。
3. **范式 C 天花板**：d′=3.77（HR=1.000，FAR=0.000，全智能体一致）——24 条著名神话/常识全部在训练语料中，测的是知识而非辨别过程。**含义**：H8 的 d′ 锚必须换用『新颖材料』（模型知识截止后的事件、或域内专业细节题），否则 θ_cal 初始化的量级锚无效。已列入电池 v2 改造项。
4. **总判定**：三范式一过一败一天花板——**验证电池本身通过了它自己的测试**：它成功区分了 LLM 与人类的效应同构域（极端度方向）与异构域（说服机制、注意力机制、知识天花板），这正是电池存在的目的。按预注册规则：B 纳入仿真先验（带机制警示标签），A、C 不得纳入，δ_human 维持文献先验。

## 限制

1. 刺激材料为模板化合成（人类实验用真实推文/新闻）——效应量不可直接外推；
2. n 小（每臂 6–8），置信区间宽；正式 H8 需 n≥20/臂 + 多模型家族（对称表 §15.2）；
3. 单模型（ornith-1.5-35b）——模型家族偏差未测；
4. LLM『立场』为陈述性角色扮演，范式 B 的通过只证明协议与管线的方向敏感性，不证明情感机制同构；
5. 范式 C 刺激全部早于模型知识截止——电池 v2 须换新颖材料。
