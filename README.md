## 项目简介

核心命题：把信息获取从"平台为目标函数优化用户注意力"重构为"智能体为自己的第二序目标函数，在统一认知预算下联合优化主动获取（pull）与被动过滤（push）"，并为此重构提供可证明的效率性、安全性、自主性与对抗性保证。

3. **升华的控制论形式化** —— 认识德性作为动力系统状态变量，人类门控的两时间尺度控制器；
4. **紧急自动化权威** —— 基于预先授权、极小化极大遗憾与可逆性偏序的安全行动框架；
5. **公共议程机制** —— 以冗余认证维持群体共享现实的下限。
